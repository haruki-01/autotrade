## 採用値: 損切り 0.35% ／ 利確 0.70%

- 6時間以内決済率 **89.9%**（目標 90%）
- レバ 3倍・証拠金 30 USDT なら想定元本 90 USDT。損切り時の損失は 0.32 USDT（証拠金の 1.1%）
- 利確時は 0.63 USDT（証拠金の 2.1%）

## 帰無仮説 — ここが判定の基準線

ドリフトのない価格では、1:2 ブラケットの当たり率は理論的に決まります。

```
P(利確が先) = 損切り幅 / (損切り幅 + 利確幅) = 1/3 = 33.3%
```

実測（無作為エントリー・決済分のみ）は **31.3%**。
理論値 33.3% との差は 2.0 ポイントで、**価格はほぼドリフトなしのランダムウォークとして振る舞っています**。

これは制約としてありがたい性質です。**勝率が33%台なら、そのシグナルには
情報がありません。** 判定はここからの上振れだけを見ればよくなります。

### 費用を織り込んだ損益分岐勝率

```
往復コスト = 90 USDT × 0.150% = 0.1350 USDT = 許容損失の 42.9%
損益分岐勝率 = (1 + 0.429) / (1 + 2) = **47.6%**
```

つまり **勝率 47.6% を超えれば黒字**です。
帰無仮説は 33.3% なので、
**情報ゼロの状態から 14.3 ポイント**押し上げないと黒字になりません。

### なぜコストがこれほど効くのか

コストの比率は損切り幅だけで決まり、**サイジングでは動きません**。

```
往復コスト / 許容損失 = コスト率 / 損切り幅 = 0.150% / 0.35% = 42.9%
```

6時間で 90% を決済するには損切りを 0.35% まで狭める必要があり、
そこまで狭いとコスト率(0.150%)が損切り幅の半分に達します。
**「6時間以内に90%決済」と「テイカー手数料」は直接ぶつかります。**

手数料の置き方を変えた場合の損益分岐勝率:

| 手数料の前提 | 往復コスト率 | コスト/許容損失 | 損益分岐勝率 | 必要な上振れ |
|---|---|---|---|---|
| 現行（両側テイカー） | 0.150% | 42.9% | **47.6%** | +14.3pt |
| 入口メイカー / 出口テイカー | 0.095% | 27.1% | **42.4%** | +9.0pt |
| 両側メイカー | 0.060% | 17.1% | **39.0%** | +5.7pt |
| 両側メイカー・スリッページ無し | 0.040% | 11.4% | **37.1%** | +3.8pt |

**入口を指値にできるかどうかで、必要な上振れが 16.7pt から 8.6pt に半減します。**
この枠組みでは手数料の置き方が最大の設計変数です。
