# コストが無視できる時間軸はどこか

戦略と無関係に、値幅とコストの比だけを測る。217本の評価でエッジがコストと同じ大きさだったので、「どの時間軸なら勝負になるか」を先に確定させる。

## 前提となるコスト

| 項目 | 値 |
|------|-----|
| 手数料（片道） | 0.055% |
| スリッページ（片道） | 0.020% |
| **往復コスト** | **0.150%（元本比）** |
| 想定元本 | 90 USDT |
| 1トレードのコスト | 0.1350 USDT |

## 時間軸ごとの値幅（ATR14 の中央値、終値比）

`cost/R` は「損切りまでの距離を 1R としたとき、コストが R の何%か」。ここが 5% を超えると、勝率や期待値の議論より先にコストで負ける。

| 期間 | 足 | ATR中央値 | cost/R (stop 1.5ATR) | cost/R (stop 2.0ATR) | cost/R (stop 3.0ATR) |
|------|-----|-----------|----------|----------|----------|
| Set A | 15m | 0.234% | 42.8% | 32.1% | 21.4% |
| Set A | 1h | 0.526% | 19.0% | 14.3% | 9.5% |
| Set A | 4h | 1.166% | 8.6% | 6.4% | 4.3% |
| Set A | 1d | 3.234% | 3.1% | 2.3% | 1.5% |
| Set B | 15m | 0.317% | 31.5% | 23.7% | 15.8% |
| Set B | 1h | 0.688% | 14.5% | 10.9% | 7.3% |
| Set B | 4h | 1.466% | 6.8% | 5.1% | 3.4% |
| Set B | 1d | 3.944% | 2.5% | 1.9% | 1.3% |
| Set C | 15m | 0.254% | 39.4% | 29.5% | 19.7% |
| Set C | 1h | 0.561% | 17.8% | 13.4% | 8.9% |
| Set C | 4h | 1.177% | 8.5% | 6.4% | 4.2% |
| Set C | 1d | 3.153% | 3.2% | 2.4% | 1.6% |

## 読み取り

- **15m**: cost/R は 15.8〜42.8% → コスト負け
- **1h**: cost/R は 7.3〜19.0% → コスト負け
- **4h**: cost/R は 3.4〜8.6% → **使える**
- **1d**: cost/R は 1.3〜3.2% → **使える**

損切りを ATR の何倍に置くかで割り引けるが、**足を遅くするほうが効き方が大きい**（ATR そのものが数倍になる）。

## 必要な ATR 水準（逆算）

cost/R を 5% 以下に抑えるには、`ATR% >= 往復コスト% / (0.05 × 損切りATR倍率)` が必要。

| 損切り | 必要な ATR（終値比） |
|--------|----------------------|
| 1.5 ATR | 2.00% 以上 |
| 2.0 ATR | 1.50% 以上 |
| 3.0 ATR | 1.00% 以上 |
