# 戦略仮説 v1（BTC-USDT / Bybit）

## 1. 一言でいうと

**日足の大きな流れと4時間足のいまの流れが同じ方向のときだけ、15分足の押し目/戻りで順張りエントリーする。**

逆方向のトレードはしない（逆張りしない）。

## 2. なぜこの仮説か

| 前提 | 仮説へのつながり |
|------|------------------|
| トレード回数は必要 | エントリー判定は15分足 |
| 秒スキャはAPI遅延的に不利 | 15分足なら判定余裕がある |
| ノイズで往復ビンタしたくない | 日足・4時間で方向フィルタ |
| レバ2〜5倍を使う | 方向が揃っているときだけ張る |

## 3. 時間足の役割（固定）

| 時間足 | 役割 | 見るもの |
|--------|------|----------|
| **日足 (1D)** | 全体トレンド | 大局の向き（Long環境 / Short環境 / 中立） |
| **4時間 (4H)** | 現在トレンド | いま追随してよいか（日足と同方向か） |
| **15分 (15m)** | エントリー | 具体的な入り・損切り・利確のタイミング |

```text
日足が Long環境
  └─ 4時間が Long方向
        └─ 15分で押し目買いのみ許可

日足が Short環境
  └─ 4時間が Short方向
        └─ 15分で戻り売りのみ許可

日足と4時間が不一致、または日足が中立
  └─ 新規エントリー禁止
```

## 4. トレンド判定ルール（v1・明確化）

過学習を避けるため、最初は単純なルールにする。

### 4.1 日足（全体トレンド）

- 指標: **EMA50（日足終値）**
- Long環境: 終値 > EMA50、かつ EMA50 が上向き（今回の終値のEMA50 > 前回）
- Short環境: 終値 < EMA50、かつ EMA50 が下向き
- 中立: 上記以外（エントリー禁止）

### 4.2 4時間（現在トレンド）

- 指標: **EMA20（4H終値）**
- Long方向: 終値 > EMA20、かつ EMA20 上向き
- Short方向: 終値 < EMA20、かつ EMA20 下向き
- それ以外: エントリー禁止

### 4.3 向きの一致条件（エントリー許可）

- Long許可: 日足=Long環境 **かつ** 4H=Long方向
- Short許可: 日足=Short環境 **かつ** 4H=Short方向

## 5. エントリールール（15分足）

「許可された方向」に対して、押し目/戻りで入る。

### 5.1 Longエントリー（押し目買い）

条件をすべて満たした15分足の確定後にエントリー検討:

1. Long許可が有効
2. 直近で価格が EMA20（15m）近辺まで押した（例: 安値が EMA20 の ±0.1%以内、または下から上へ復帰）
3. 当該15分足が **陽線**（終値 > 始値）で、押し目からの反転を示す

注文: **成行買い**（v1はシンプル優先）

### 5.2 Shortエントリー（戻り売り）

1. Short許可が有効
2. 直近で価格が EMA20（15m）近辺まで戻した
3. 当該15分足が **陰線** で反転を示す

注文: **成行売り**

### 5.3 同時ポジション

- 最大ポジション: **1つ**（建玉中は新規なし）
- ドテン（反対売買での即逆転）は v1 ではしない。決済してから次へ。

## 6. エグジットルール（15分足）

### 6.1 損切り（必須）

- Long: エントリー足の安値、または直近スイング安値の小さい方の外側（バッファ少し）
- Short: 対称
- v1の仮ルール: **エントリー価格から 1.0% 逆行で損切り**（あとでATR化を検討）

### 6.2 利確（必須）

v1の仮ルール（どちらか先に到達）:

- **利確**: エントリーから **1.5%** 順行
- または **4Hトレンド崩壊**（4H終値がEMA20を明確に割り込み/上抜け）で決済

※ 1.0%損切り / 1.5%利確は「仮」。バックテストで期待値と回数を見て調整する。  
　ただし **最適化のやりすぎ禁止**（1組〜少数の候補のみ試す）。

### 6.3 時間足由来の強制決済

- 日足が中立または逆環境に変わったら、次の15分確定で決済を検討（v1では「逆環境になったら決済」）

## 7. ポジションサイズ・レバ（v1）

- レバレッジ: **3倍を初期値**（許容レンジ2〜5）
- 1トレードのリスク: 口座残高の **0.5〜1.0%** 相当を損切り幅から逆算（実装時に確定）
- 証拠金の全振りはしない

## 8. 仮説が正しいときに起きること

- トレンド相場で、方向フィルタが効き、逆方向の負けが減る
- 15分の押し目/戻りで入れるため、月に一定回数のトレードが発生する
- レンジ相場では日足・4Hが中立/不一致になり、トレード回数が減る（それは想定内）

## 9. 仮説が間違っているときに起きること

- コスト控除後の期待値がマイナス
- DDが深い（ダマシの押し目が続く）
- トレード回数が極端に少ない、または多すぎて往復損

→ その場合はエントリー条件を見直す。時間足の役割（1D/4H/15m）自体は当面変えない。

## 10. 意図的に入れないもの（v1）

- ファンディングレート予測
- 板・オーダーブック
- ニュースイベントフィルタ
- 複数指標の合成スコア
- 秒・1分足
