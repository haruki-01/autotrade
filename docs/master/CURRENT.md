## 1. 理想状態

### Phase 1 で「できた」と言える状態

**GMOコイン**の **BTC レバ（個人最大2倍）1本**を、同じルールで **バックテスト → demo → 少額 live** まで通した bot が1つある。

| 層 | 到達イメージ |
|---|---|
| 口座 | 少額元本。証拠金ベース。レバ **2**（国内上限）。同時建玉 **1枠**。複数口座・複数銘柄は作らない |
| 検証の合格 | 費用後 EV が 3期間ともプラス。最大 DD ≤ 20%。期間ごと n&lt;100 は不合格ではなく **判定保留**（プールの t で読む） |
| 存在理由 | 春希さんが一文で言える。「下落で買い持ちより壊れない」は数字で出ている。上昇期に買い持ちの Return/DD に負けてよい（合否ではない）が、そのとき **なぜ持たずに bot を回すか** は決めてある |
| 運用 | demo で注文とポジションがずれない。live はフラグと別キーなしでは起動しない |
| 非目標 | Web UI、2本目ロジック、秒スキャ、板の先頭 |

### 到達しないもの（別軸。合否にしない）

| 軸 | 扱い |
|---|---|
| **月120%**（元本300で月360） | 実測の最良 N×Q² の約17倍。願望・逆算用。詳細は [TARGET_MODEL.md](./TARGET_MODEL.md) |
| **月50エントリー** | 1枠・日足規模と両立しない。履歴として残すだけ |

「月120%を目指す」と「費用後に黒で DD を守る」は別のプロジェクトに近い。今の Phase 1 は後者。

## 3. いまどこまで来たか（1画面）

エンジン（データ・BT・コスト・lock）はある。Bybit testnet 向け demo スケルトンはあるが、**日本居住では Bybit キーが作れない**。live は未着手。

| 探索 | 結論 | 状態 |
|---|---|---|
| 15m 固定利確ファミリー（H01 など） | 費用負け | 棄却 |
| 価格外 EH 100本 | 機構は一部残る。水準がコストに届かない | 棄却 |
| 12h ブラケット（利確1.5%帯） | 1年で決済EV黒 0。入口を足しても埋まらない | **打ち止め** |
| **SH-01** 50日 / 100日休む条件 | EV+DD PASS（Bybit 費用モデル）。Set C の Return/DD は買い持ちを上回る | **本命。再現性の強化が先** |

SH-01 中心（`sh01n_center`）要約: 3期間 EV +1.951 / +0.528 / +0.456、DD 2.8 / 5.3 / 7.6%、プール n=164 EV +0.989 t=+2.57。  
正本: [eval/reports/20260825-slow-evdd.md](../../eval/reports/20260825-slow-evdd.md)

残っている優位は主に **DD**（数%対、買い持ちの50%超）。リターンの桁は「持っている」方が大きい上昇期がある。

保有の実測（`regime_100d` プール）: 中央値 **約4日**、平均約7日。24h以内に縮めると別戦略になる。

## 4. いま検証・判断すべき論点

新しい入口条件を増やす段階ではない。上から順。

### 論点A（決定 2026-08-25）

春希さん: **50日と100日の休む条件を採用。** 1枠なので注文ロジックは1本（既定100日）。

### 論点B（実施済み 2026-08-25）

休む条件を中心設定に1点足した。正本: `eval/reports/20260825-slow-rest.md`。

- **3期間とも Return/DD で買い持ちを上回るのは `regime_50d` と `regime_100d`**
- `regime_100d` がプール t 最大（+3.01）

### 論点C'（いまここ・2026-08-26 更新）

春希さん: **取引所は GMO ベースで考える。ただし先に「再現性高く勝てる」構築。**

1. SH-01 の再現性・費用後黒を、入口を増やさずに固める（期間符号・プール t・買い持ち対比）
2. 次に **GMO コスト**（スリッページ＋建玉管理料 0.04%/日・レバ2）で formal 再評価
3. 通ったら GMO API / demo。Bybit `--submit` は居住制限のため進めない

### 今やらないこと

- 12h / 利確1.5% の入口探索
- 月50回のための高速ロジック
- 6銘柄バスケットに戻す
- `min_trades` を下げる
- 月120%をゲートにする
- ノブの同時変更、期間を見て再最適化
- **今すぐの GMO アダプタ実装**（エッジが固まってから）
- Bybit testnet / Demo Trading への依存
