## 2. 最初に書くべき検証仮説（詳細）

### L-COST（費用ゲート）

- **歪み:** 弱いシグナルの連打は、予測が当たっても費用で負ける（E8）
- **ルール:** エントリー候補に対し、想定ストップ幅（ATR）から「必要値動き」を見積もり、往復fee+slip+余裕を下回るならスキップ
- **棄却:** スキップを入れても純EV・DDが改善しない
- **優位:** 多くのAI/個人はここを無視して過売買する

### L-MOM-VOL（本命）

- **歪み:** トレンド継続（E1）＋ボラクラスタ（E6）
- **ルール骨子:**
  - 日足で方向（例: 終値 vs SMA200 または Donchian状態）
  - 4Hで「今ついてよいか」（ADXまたはSupertrend）
  - 15mは執行（ブレイクまたは浅い押し）。**利確は固定%にしない**（ATRトレール／構造割れ）
  - サイズ = 口座リスク% / ATRストップ
- **棄却:** OOS純EV≤0、利益の大半が単月、DD運用不能
- **v1との差:** 固定1.5%利確を捨て、ボラでサイズする → 「大勝ちを残す」

### L-BREAK

- **歪み:** E1（ブレイクで乗る）
- **ルール:** 日足20または55 Donchian、逆側短いチャネルで退出、ATRストップ
- **Long only比較必須**（H21）
- **棄却:** コスト後EV≤0
