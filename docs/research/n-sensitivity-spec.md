# N 感度検証仕様（P1-N）

月間トレード回数 \(N\) を **10 / 20 / 50 / 100** の4候補とし、手数料込みの必要勝率・必要 EV を整理した上で H-D + H-M4 を検証する。

L0: [SPEC.md](../SPEC.md)（Gate2 = +5%/月、\(P^* = 0.05 \times B\)）

## 2. N 候補と必要エッジ（初期 BR ¥50,000、Q = ¥10,000）

Gate2: \(P^* = ¥2,500\)/月（+5%）

| 目標 N | N 帯（±20%） | 必要 EV* | EV*/Q | 損益分岐 W（RR 1:2, SL=0.8%） |
|---:|---|---:|---:|---:|
| 10 | 8–12 | ¥250/回 | +2.50% | 35.0% |
| 20 | 16–24 | ¥125/回 | +1.25% | 35.0% |
| 50 | 40–60 | ¥50/回 | +0.50% | 35.0% |
| 100 | 80–120 | ¥25/回 | +0.25% | 35.0% |

**損益分岐 W** = `fee_breakeven_win_rate(0.008, 0.016)` — 取引手数料 0%、レバ 0.04%/日は保有時間依存のため保守的に往復 0.04% を込み。

**Gate2 到達に必要な W**（RR 1:2、SL=0.8%、TP=1.6%、コスト c=0.04% 往復想定）:

\[
W^* = \frac{EV^*/Q + SL + c}{SL + TP}
\]

| N | W*（Gate2） | 備考 |
|---:|---:|---|
| 10 | **139%** | RR 1:2 では構造的に不可（最大 EV ≈ ¥156/回 @ W=100%） |
| 20 | 87.1% | 高勝率が必要 |
| 50 | 55.8% | 現行 W≈55% でギリギリ未達 |
| 100 | 45.4% | W は達成可能だが N 帯調整困難 |

## 3. 葉ルール（N 調整）

| 項目 | ルール |
|---|---|
| ベース | H-D pull + H-M4（P1-C 同一） |
| N 調整 | **cooldown** を二分探索（12–576 本）し `monthly_n` を目標 N 帯中央に近づける |
| 固定 | pct_risk=0.008, atr_mult=0.5, max_bars=48 |
| 評価 split | OOS1 + OOS2（執行込み） |

---

## 4. 合格ゲート（N 別）

| ゲート | 条件 |
|---|---|
| **Gate1@N** | EV > 0 かつ N が当該帯内 |
| **Gate2@N** | 月次 P ≥ ¥2,500（初期 BR 基準） |
| **W check** | 実測 W ≥ W*（Gate2 必要勝率） |
