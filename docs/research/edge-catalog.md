# エッジ仮説カタログ

仕様書 §6 の初期5本を含む、メカニズム単位の網羅一覧。  
**検証の進捗・統計結果は本ファイルではなく Phase0 シート側に書く。**

共通前提: BTC/JPY / 分足以上 / N帯≈50 / 必要EV≈+0.5%（Gate2、詳細は SPEC）。Stretch +2.0%（+20%/月）は参考。

## 仮説カード必須項目

1. 誰が歪ませるか  
2. 観測可能なトリガー  
3. 取り方（継続 / 回帰 / フィルタ）  
4. 遅入・禁止条件  
5. 必要データ  
6. Phase  
7. 記述統計での棄却指標（Phase0）

L1（メカニズム）が書けない案はカタログに載せない。
