# Phase0 記述統計 — 定義書

トレードロジックは組まない。  
**イベント定義 → フォワード指標 → ベースライン比較 → 進む/棄却** だけを行う。

定数（資金・N・執行）は SPEC 参照。本定義は統計の測り方だけを固定する。

---

## 1. 共通設定

| 項目 | 定義 |
|---|---|
| 銘柄 | BTC/JPY |
| 基準足（イベント検出） | **5分足**（感度分析: 1分） |
| 文脈足 | 1時間 / 12時間（条件付き分割用） |
| タイムゾーン | **Asia/Tokyo (JST)** |
| サンプル期間 | 記入時に明記（例: 2024-01-01〜2025-12-31） |
| 最低イベント数 | 原則 **n ≥ 100**（稀イベントは n ≥ 30 で探索扱い） |
| リターン定義 | \(r(h) = \frac{close_{t+h} - close_t}{close_t}\)（イベント確定足の終値基準） |
| 方向付きリターン | 仮説が「上期待」なら \(r\)、「下期待」なら \(-r\)。符号付きで **edge_return** と呼ぶ |
| ATR | 5m ATR(14)。イベント足で計算 |
| ベースライン | 同一期間の **ランダム同時刻オフセット**、または「全5m足の同ホライズン平均」 |

### 1.1 必須アウトプット列（すべての統計行）

| 列 | 意味 |
|---|---|
| n | イベント数 |
| hit_rate | edge_return(h*) > 0 の割合（主ホライズン h*） |
| mean_edge | edge_return(h*) の平均 |
| median_edge | 中央値 |
| p25 / p75 | 四分位 |
| mean_abs_move | \|r(h*)\| の平均（大きさ） |
| vs_baseline | mean_edge − baseline_mean（または差の検定 p値） |
| verdict | **pass / weak / fail / insufficient_n** |
| notes | 自由記述 |

### 1.2 判定ルーブリック（初期）

厳密な有意水準より、次の実務ルーブリックを使う（後で改定可）。

| verdict | 条件（目安） |
|---|---|
| **pass** | n十分、かつ mean_edge がベースラインより明確に大きく、hit_rate ≥ 0.55、主ホライズンで符号が安定 |
| **weak** | 方向は合うが効果小、または時間帯・サブサンプルでのみ出る |
| **fail** | 符号が逆、またはベースラインと差がない |
| **insufficient_n** | n 不足 |

Phase1 へ進める候補: **pass**、または明確な条件付き **weak**（条件を葉に固定できる場合）。

### 1.3 共通ホライズン

イベント後の計測窓（5mバー数）:

| ラベル | バー数 | 実時間 |
|---|---|---|
| h15 | 3 | 15分 |
| h30 | 6 | 30分 |
| h60 | 12 | 1時間 |
| h120 | 24 | 2時間 |
| h240 | 48 | 4時間 |

シート上の主ホライズン h* は仮説ごとに指定。副次は参考記録。

## 2. 共通ヘルパー定義

### HELPER-VOL｜実現ボラ

- `rv_n` = 直近 n 本の 5m log-return の標準偏差（年率化しない）  
- 圧縮: `rv_20` が過去 20 営業日の `rv_20` 分布で下位 20%  
- 急騰: `rv_20` が同分布で上位 10%、または当該足 range ≥ 中央値 range × 2.5  

### HELPER-SWING｜スイング高安

- 5m: 左右 6 本より高い高値 / 低い安値をスイング  
- 参照レンジ: 直近 24 本（2時間）の high max / low min  

### HELPER-SESSION｜セッション

| ラベル | JST |
|---|---|
| TOKYO | 09:00–15:00 |
| EUROPE_US | 16:00–24:00 |
| OFF | 上記以外（深夜〜朝） |
| FEE_WINDOW | 05:30–06:30（H-E 用） |

### HELPER-WEEKDAY

- WD = 月–金、WE = 土日  
- WEEK_OPEN = 月曜 00:00–12:00 JST

## 3. Phase0 統計項目（仮説別）

各項目 ID はシートの行キーと一致させる: `P0-<仮説ID>-<指標略号>`

---

### 3.1 H-A / H-A2｜スパイク後の回帰 vs 継続

**イベント `SPIKE`**
- 5m close が直近24本レンジを外側に突破  
- 突破幅 ≥ 0.4 × ATR  
- 当該足 range ≥ 直近100本 range 中央値 × 2.5  

**方向**
- 上抜け SPIKE_UP / 下抜け SPIKE_DOWN  

| 項目ID | 測るもの | 定義 | h* | 進む条件の目安 |
|---|---|---|---|---|
| P0-HA-REVERT | 回帰エッジ | edge = 突破と逆方向への return | h60 | 回帰 mean_edge が継続より大 → H-A 有力 |
| P0-HA-CONT | 継続エッジ | edge = 突破同方向への return | h60 | 継続が大 → H-A2 有力 |
| P0-HA-REVERT15 | 短期回帰 | 同上 | h15 | 吸い戻しが超短期か |
| P0-HA-PATH | 経路 | 先に 0.3×ATR 逆行する割合 vs 同方向 1×ATR 伸ばす割合 | — | 執行タイミング設計用 |
| P0-HA-BY-SESS | 条件付き | P0-HA-REVERT を SESSION 分割 | h60 | 特定帯のみなら C と結合 |

**対照ルール**: 同一イベント集合で REVERT と CONT を必ず両方出す。

---

### 3.2 H-A3｜ダブルストップ

**イベント `DOUBLE_SPIKE`**
- 6時間以内に SPIKE_UP と SPIKE_DOWN が両方発生  
- 2回目スパイク確定時点を t  

| 項目ID | 測るもの | 定義 | h* |
|---|---|---|---|
| P0-HA3-REVERT2 | 2回目後の回帰 | 2回目と逆方向 edge | h60 |
| P0-HA3-RATE | 発生頻度 | 月あたり DOUBLE_SPIKE 回数 | — |

---

### 3.3 H-A4｜レンジ端反転失敗

**イベント `FAILED_EDGE_REVERSAL`**
- 直近24本レンジの端（上下 ATR0.1 以内）にタッチ  
- その後 3 本以内にレンジ内へ戻らず、代わりに外側へ 0.5×ATR 以上進行  

| 項目ID | 測るもの | 定義 | h* |
|---|---|---|---|
| P0-HA4-CONT | 失敗後継続 | ブレイク方向 edge | h120 |
| P0-HA4-FALSE | 偽陽性 | 同定義でも h120 で逆行する率 | h120 |

---

### 3.4 H-B｜モメンタム点火

**イベント `IGNITE`**
- 同方向 close が 3 本連続  
- 各足の実体 ≥ 直近100本実体中央値 × 1.5  
- 3本目確定時点を t  
- 除外: 12h が明確逆配列（任意分割でも計測）  

| 項目ID | 測るもの | 定義 | h* |
|---|---|---|---|
| P0-HB-EARLY | 早期エッジ | 点火方向 edge（t=3本目） | h120 |
| P0-HB-LATE | 遅入比較 | 起点から既に +1.5% 以上のサブサンプルの edge | h120 |
| P0-HB-PULL | 初押し後 | 点火後、伸びの 20–40% 戻してからの edge | h120 |
| P0-HB-FREQ | 頻度 | 月あたり IGNITE 数（N=50 実現可能性） | — |
| P0-HB-BODY | 実体フィルタ効果 | 実体条件あり/なしの mean_edge 差 | h120 |

**鍵**: EARLY ≫ LATE なら「早期性」がエッジ。差が無ければ H-B の核心は棄却。

## 4. 実行順序（推奨）

1. **低コスト棄却**: P0-HE-* , P0-HC4-* , P0-HC-*  
2. **コア分岐**: P0-HA-REVERT vs CONT , P0-HB-EARLY vs LATE  
3. **点火族**: P0-HB2-* , P0-HB3-*  
4. **押し・レジーム**: P0-HF1-* , P0-HF2-*  
5. **群集**: P0-HD-* , P0-HD2〜5  
6. **稀イベント**: P0-HA3-* , P0-HC2-* , P0-HB4-*
