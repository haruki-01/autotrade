調査時点の整理。数値は各社公式・二次情報の要約で、**開設前に公式手数料表で再確認**すること。  
法務の最終判断は専門家へ。

## これまでの取引条件との突合

| 条件（現行） | 国内での現実 |

| SH-01 は日足規模で持ち越しあり | **建玉管理料 約0.04%/日** が費用の本丸（往復takerだけ見ない） |

## 複合判断の軸

1. **安全性** … 金融庁登録・大手・預かり資産・事故歴の見え方  
2. **商品適合** … BTC レバ（証拠金／CFD）があるか  
3. **API** … 注文・建玉・残高が公式 Private API でできるか  
4. **費用** … 約定手数料＋日次建玉管理料＋ロスカット手数料＋入出金  
5. **少額運用** … 最小数量・板の厚さ（スリッページ）

## 費用試算（必要勝率の目安）

前提（現行口座）: リスク 3 USDT / 証拠金 30。SH-01 中心の利確/損切比 ≈ **4ATR : 1.5ATR（RR≈2.67）**。  
Bybit 検証コスト: 往復 **0.15%**（fee 0.055%×2 + slip 0.02%×2）。  
国内レバ（GMO/bitFlyer 系）: 約定無料寄り、スリッページ往復 **0.04%**、建玉管理料 **0.04%/日**（両建想定）。個人レバ上限 **2倍** → 想定元本おおむね **50〜60 USDT**。

ゼロコストの損益分岐勝率（純TP/SL）: **27.3%**。  
Bybit（往復0.15%、持ち越しなし）: 約 **28.0〜28.5%**。

| 保有日数 | 国内コスト目安（元本60） | 損益分岐勝率 | Bybit比の上昇 |
|---|---|---|---|
| 1日 | 約 0.05 USDT（0.02R） | 約 27.7% | **ほぼ同じ〜やや有利** |
| 5日 | 約 0.14 USDT（0.05R） | 約 28.6% | **+0.3〜0.5pt** |
| 7日 | 約 0.19 USDT（0.06R） | 約 29.0% | **+0.5〜0.9pt** |
| 14日 | 約 0.36 USDT（0.12R） | 約 30.5% | **+2pt前後** |
| 21日 | 約 0.53 USDT（0.18R） | 約 32.1% | **+3.5〜4pt** |
| 30日 | 約 0.74 USDT（0.25R） | 約 34.0% | **+5〜6pt** |

読み方:

- SH-01 Set B の実測勝率はおおよそ **37〜39%**（構造決済込み）。分岐が 29〜30% ならまだ余裕はあるが、**保有が長いほど EV（1回あたり約 +0.5〜+1.3 USDT）を日次で削る**。
- 目安: 元本60で **1日あたり約 0.024 USDT（約 0.008R）** が建玉管理料。14日持つと約 0.36 USDT ≈ 実測EVの半分前後が費用に消えるイメージ。
- GMO のロスカット手数料（例: 建玉×0.5%）は別枠。通常決済の試算には入れてない。
- これは **損益分岐の机上試算**。正式には国内コストモデルで `eval_v3` を再実行して判断する。

- Bybit の「レバ3・USDT無期限」はそのまま移植できない → **レバ2・BTC/JPY・国内コストモデルで再検証**が必要
