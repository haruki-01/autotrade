# 国内取引所候補（日本居住・BTC自動売買）

調査時点の整理。数値は各社公式・二次情報の要約で、**開設前に公式手数料表で再確認**すること。  
法務の最終判断は専門家へ。

## これまでの取引条件との突合

| 条件（現行） | 国内での現実 |
|---|---|
| Bybit BTC-USDT 無期限 | **利用資格が崩れている**（日本＝サービス対象外） |
| レバ **3** | 個人は概ね **最大2倍**（規制）→ 条件の見直し必須 |
| 元本〜300 USDT・証拠金30・1枠 | 少額可。銘柄は多くが **BTC/JPY**（USDT建てではない） |
| API で demo → live | **金融庁登録業者**かつ **レバ＋Private API** がある先に限定 |
| SH-01 は日足規模で持ち越しあり | **建玉管理料 約0.04%/日** が費用の本丸（往復takerだけ見ない） |

## 複合判断の軸

1. **安全性** … 金融庁登録・大手・預かり資産・事故歴の見え方  
2. **商品適合** … BTC レバ（証拠金／CFD）があるか  
3. **API** … 注文・建玉・残高が公式 Private API でできるか  
4. **費用** … 約定手数料＋日次建玉管理料＋ロスカット手数料＋入出金  
5. **少額運用** … 最小数量・板の厚さ（スリッページ）

## 第一候補の読み（要約）

**まずは GMOコインと bitFlyer の2社に絞るのがよい。**

- 両方とも金融庁登録・BTCレバ・公式APIがある  
- 費用の支配項は「往復手数料」より **持ち越し日数 × 約0.04%/日**（SH-01向き）  
- Bybit の「レバ3・USDT無期限」はそのまま移植できない → **レバ2・BTC/JPY・国内コストモデルで再検証**が必要
