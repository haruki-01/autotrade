# SPOT-001 ダブルボトム族 — 変数地図と20サイクル設計

春希さんの仮説を正本にし、**1サイクル＝1ノブ**で測り方を変える。

## min_trades について（先に）

| 項目 | 値 |
|------|-----|
| `min_trades` | **100** |
| 対象期間 | **Set B = 1年**（2024-01-01〜2024-12-31）。**1ヶ月ではない** |
| 意味 | その1年間の合計トレード数。月100ではない |

足を短くすると回数は増えうるが、**1分未満は見ない**（本バッチの執行は15m、構造は1H/4H/日足）。
