# 仮説カタログ v1（検証候補）

最終更新: 2026-08-22

目的: **精度の高い（=ルールが曖昧でなく、過去データで合否が出せる）仮説をたくさん用意する。**  
いまは実装しない。先に候補を並べ、次に少数をバックテストする。

前提（このプロジェクト）:
- 取引所: Bybit BTCUSDT 無期限（研究データは Binance Vision でも可）
- 時間足の役割は原則維持: **日足=全体 / 4時間=現在 / 15分=エントリー**
- レバ 2〜5（初期3）
- 合否はコスト込み（手数料・スリッページ）。合成データでは判定しない

注意:
- 「YouTubeで勝っている人」の手法は、**裁量（後付けで説明できる）ものが多く、そのままでは検証できない**
- 公開バックテストは期間・コスト・レバがバラバラ。**数字を信用せず、自分のデータで再検証する**
- 仮説 v1（EMA押し目）は 2024 Set B で **FAIL**。同じ型の微調整より、**別ファミリーを先に試す**方が学習効率が良い

## 2. 各仮説の詳細（検証用スペック）

共通ルール（全仮説）:
- 足は確定後に判定。約定は次足始値 ± スリッページ
- 同時ポジは1つ
- 1トレードリスクは口座の 0.5〜1%（ATRまたはストップ幅から逆算）
- Set B（2024）で主判定、Set C で耐久。パラメータはBで再最適化しない

---

### H01（既存・FAIL）EMAマルチTF押し目

- 日足 EMA50 順方向、4H EMA20 同方向、15m EMA押し目で成行
- 損切1% / 利確1.5%
- 結果: 2024 実足で期待値マイナス、DD 49%
- 学び: **固定%利確はトレンドを切れ、押し目条件が緩いと回数過多で手数料負け**

---

### H02 Donchian 20/10（Turtle System 1 簡易）

**仮説一文:** BTCはトレンドが長く続く。N日高値更新で入り、短い逆方向ブレイクで抜けると、ダマシを飲みつつ大波を取れる。

公開の根拠:
- Turtle Traders（Dennis）の公開ルール
- BTC日足Donchianの公開バックテスト記事が複数（20入り/10抜けが定番）

ルール:
- **日足:** 終値が過去20日高値を更新 → Long許可。過去20日安値更新 → Short許可（H21と組むならShortなし）
- **4H:** 使わない、または「日足と同方向の4H終値」だけ確認
- **15m:** 日足シグナルが出た次の15mで執行（または4H確定を待つ）
- 決済: 終値が過去10日安値（Long）/高値（Short）を割る
- ストップ: 2×ATR(20)（Turtle流）

データ: 1D必須。15mは執行タイミング用。

棄却条件: コスト後期待値≤0、またはDD>35%（トレンド系はDDが深くなりがち。20%ゲートは別途「サイズ縮小」で再評価）

---

### H03 日足200SMA の上だけLong

**仮説一文:** 200日線の上は強気レジーム。下では新規Longしない（またはフラット）方が、暴落のDDを減らせる。

公開の根拠:
- 株・BTCとも「200SMAはフィルタ」として広く使われる
- 金クロス（50/200交差）より、単純な価格 vs 200SMA の方が反応が速い、という公開比較あり

ルール:
- 日足終値 > SMA200 → Long環境
- 日足終値 < SMA200 → 新規禁止（既存は決済）
- エントリーは H02 または H05 に委譲（この仮説単体でも「200上でドンチアン」合成可）

棄却: フィルタなし比でDDが改善しない、かつリターンも落ちる

---

### H04 Supertrend 日足（ATR=10, 倍率3）

**仮説一文:** ATR帯を終値が明確に超えた方向についていき、帯をトレールすれば、固定利確より大波を残せる。

公開の根拠:
- Supertrend（Seban）はトレンド系の定番
- BTC日足の公開BTあり（Buy&Hold比でリターンは劣ってもDDは浅い、という報告）

ルール:
- 日足 Supertrend が陽転 → Long、陰転 → 決済（Long only推奨）またはドテン
- 15mは「日足確定の翌15mで執行」のみ
- 4Hは任意フィルタ（同方向ならエントリー）

棄却: トレードが年数回しかなく判定不能、またはコスト後にBuy&Hold+DD削減のどちらも満たさない

---

### H05 4H Supertrend × 日足順方向 × 15m押し目

**仮説一文:** 日足で方向、4H Supertrendで「今ついてよいか」、15mは押し目だけ。v1のEMA20よりボラ適応する。

公開の根拠:
- 上位足Supertrend + 下位足執行はFX/Crypto教材の定番構成
- 4Hは日足より回数が出る

ルール:
- 日足: 終値 > EMA50（または Supertrend陽）
- 4H: Supertrend(10,3) が日足と同方向
- 15m: ATR押し目（終値が4H Supertrend帯に接近後、陽線確定）
- 損切: 15m Supertrend または 1.5×ATR(15m)
- 利確: トレール（H22）。固定%にしない

これは **v1の後継候補No.1（同ファミリー改良）**

### H06 ADXレジーム分岐

**仮説一文:** ADXが高いときだけ順張り。ADXが低いときは見送り（またはH08の逆張りに切替）。v1の往復負けは「レンジで順張りした」せい、という仮説。

公開の根拠:
- ADX>20〜25をトレンド確認に使うのは教材・論文系アルゴリズムで頻出
- 逆に「ADX低いときだけブレイク」という逆フィルタ公開例もある（H13）

ルール（順張りモード）:
- 4H ADX(14) > 20 のときだけ H02/H05 の新規を許可
- ADX ≤ 20 はフラット維持

検証のポイント: トレード数が100を割らないか。割りすぎたらADX閾値は触らず、エントリー足を4Hに上げる。

---

### H07 ATR損切り（v1の1%を置換）

**仮説一文:** BTCの1日レンジは時期で倍以上変わる。固定1%損切は、静かな相場では広すぎ/荒い相場では狭すぎて、期待値を壊す。

ルール:
- ストップ = 1.5×ATR(14) on 15m または 2×ATR on 4H
- 利確は 2R（リスクリワード固定）またはトレール
- エントリー条件は v1のまま、出口だけ変える（**1点変更の原則**）

公開の根拠: Turtle、多くのクオンツ本でATRサイズが標準。

---

### H08 ボリバン外 + RSI 極端（レンジ限定）

**仮説一文:** レンジでは平均に戻る。ボリバン2σ外 + RSI30/70 で逆張りし、ミドルバンドで利確。

公開の根拠:
- BB+RSIは平均回帰の最も一般的な機械ルール
- 公開1H BTCでは負け例もあり → **ADX低のときだけ**が肝

ルール:
- 許可: 4H ADX < 20（トレンドでない）
- 15m: 終値が下限バンド割れ、RSI(14)<30、次足がバンド内復帰でLong（Shortは対称）
- 利確: ミドルバンド
- 損切: バンド外の1.5倍幅
- 日足が強いトレンド（H03の200SMA明確）ならこの仮説はオフ

棄却: トレンド年（2024のような）で大損するなら「自動オフ」が必須。オフ後に残るなら採用検討。

---

### H09 資金調達率の行き過ぎ逆張り

**仮説一文:** 無期限は混み合うとfundingが極端になる。極端なプラスはLong過密→下、極端なマイナスはShort過密→上、へ戻りやすい。

公開の根拠:
- Bybit/先物解説の定番（混み合い指標）
- 実務閾値の例: ±0.03%〜0.05%/8h を「熱い」とする記事が多い（要データで校正）

ルール（仮）:
- 直近fundingが過去90日で上位5% かつ 4H RSI過熱 → Shortのみ（日足中立〜弱気）
- 下位5% かつ RSI売られすぎ → Long
- 保有は短め（次のfunding 1〜3回、または価格がSMA20へ回帰）
- **トレンド日足と逆行するならサイズ半減 or 見送り**（トレンドに逆らうのが失敗パターン）

データ: Bybit funding履歴（公開API）。CloudからBybit不可なら手元で取得。

### H10 ロンドン〜NY時間のみ新規

**仮説一文:** BTCの価格発見・出来高は欧米時間に集中。アジア深夜の15mシグナルはダマシが多い。

公開の根拠:
- 学術: LNY重複時間帯に出来高・ボラ・価格発見が集中
- 実務: 13:00–16:00 UTC 前後が重複、と複数メディア

ルール:
- 新規エントリー許可: 07:00–21:00 UTC（広め）または 13:00–16:00（狭め）
- 既存ポジの損切は時間外も有効
- 他の仮説（H05等）のフィルタとして検証

棄却: 回数減だけで期待値が改善しない

### H11 Donchian 55/20（Turtle System 2）

H02より遅い。公開crypto解説では「20日はダマシ多い、55日の方が良い」という主張がある。

ルール: 日足 55日高値でLong、20日安値で決済。ShortはH21とセットで切ってもよい。

H02と同時最適化しない。**別仮説として同じゲートで比較。**

### H12 ブレイク確認後の押し目（v1改良）

**仮説一文:** v1は「EMA近辺の陽線」が緩すぎる。先に4Hで高値更新（構造の切り上げ）があってから15m押し目、にするとダマシが減る。

ルール:
- 日足 Long環境
- 4H: 直近20本高値を終値で更新した「あと」
- 15m: EMAまたはVWAPへの押し、確定陽線
- 損切: ブレイク起点のスイング安値
- 利確: トレール or 2R

v1との差分は **「先にブレイク」があることだけ。**

### H13 ボラ圧縮からのブレイク

**仮説一文:** 静かな相場のあとに出るブレイクは、ノイズのブレイクより続きやすい。

公開の根拠: 低ADX時にDonchian、ボリバン幅縮小後のバンドウォーク、など。

ルール:
- 4H: ATR(14) が過去50本の下位20%（圧縮）
- その後15mまたは4Hで20本高値/安値ブレイク
- 損切: 圧縮レンジの反対側
- 利確: 圧縮幅の2倍、またはATRトレール

### H14 金クロスは「許可」、死クロスは「Long禁止」

**仮説一文:** 50/200交差をエントリーに使うと遅すぎる。状態フラグとして使う。

ルール:
- SMA50 > SMA200 → H05のLongのみ許可
- SMA50 < SMA200 → Long新規禁止（Shortは別仮説）

金クロス単体エントリーはトレードが少なすぎて、このプロジェクトの「回数も欲しい」条件と衝突しやすい。

### H17 清算スパイク後の逆張り

**仮説一文:** 強制決済で行き過ぎた価格は、短時間で平均に戻る。

ルール（機械）:
- 15m リターンが過去500本で下位1%（暴落バー）
- 次の1〜4本で陽線確定ならLong（暴騰ならShort）
- 利確小さく（0.5〜1%）、損切同程度
- 日足大トレンドに逆らう場合はスキップ

データ: 価格だけでも「極端バー」近似は可。本物の清算高はBybit公開データが望ましい。

### H18 機械化FVG（Fair Value Gap）

YouTube/ICTで非常に多い。**埋め率の公的な検証は弱い。** 定義だけ機械化する。

定義:
- 3本の15mで、1本目高値 < 3本目安値（上昇ギャップ）または逆
- 日足・4H順方向のときだけ、ギャップに価格が戻ってタッチしたら順張り
- 損切: ギャップの反対側
- 「必ず埋まる」は仮定しない。**タッチ後の順張り継続**だけテスト

ランクC。H05等が全滅したとき用。

---

### H19 スウィープ（高値/安値割れ即戻し）

定義:
- 15mが直近20本の安値を一度割るが、終値は戻す（ロング下ヒゲ）
- 日足Long環境 + 4H Long のときだけLong
- 損切: スウィープの最安
- 利確: 1.5〜2R

Wyckoffのspringに近い。ICT物語（誰が狩ったか）は検証不要。パターンだけ見る。

### H20 出来高確認ブレイク

- H02/H12のブレイク時、出来高が20本平均の1.5倍以上
- 満たさなければスキップ

### H21 ロングオンリー

**仮説一文:** BTCの長期ドリフトは上。同じシグナルでもShortが期待値を壊している。

検証方法: H02/H04/H05 を Long only と Long+Short で同じ期間比較。  
2024は上昇年なので、**上昇年だけで勝つのは不十分。下降年（Set Aの一部や2022があれば）も見る。**

---

### H22 固定利確をやめる（トレール）

**仮説一文:** トレンドフォローの期待値は少数の大勝ちに依存する。1.5%利確はそれを殺す（v1失敗の有力原因）。

ルール:
- 初期損切: ATR
- 1R順行で損切を建値へ
- その後 ATRトレール、または4H Supertrend割れで決済
- エントリーは一旦 v1のまま、出口だけ変更（H07と同時に変えない。先にH22単体）
