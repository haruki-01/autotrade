## 1. 結論（先に）

**このプロジェクトで初めて、3期間すべてでゲートを通ったロジックが出ました。**

| | EV(A) 2023 | EV(B) 2024 | EV(C) 2025-26 |
|---|-----|-----|-----|
| `sh01_tp_4atr` | +0.731（n=133, DD 14.4%） | +0.595（n=143, DD 13.9%） | +0.537（n=212, DD 18.9%） |

ただし採用の判断材料として重要なのは、この1本ではなく次の3つです。

1. **系統全体がプラス。** 23本中20本が3期間すべてで EV プラス。一点ではなく面
2. **買い持ちに対して意味がある。** バスケットが −33.1% だった Set C で **+38.0%**（DD 18.9% 対 64.2%）
3. **1日遅らせても残る。** シグナルを丸1日ずらしても3期間すべてでプラス → 先読みではない

そして EV の桁が変わりました。**±0.05 → +0.3〜+3.1 USDT/トレード**です。
ロジックが賢くなったからではなく、コストの掛かり方を直しただけです。

## 2. 何を変えたのか — 1点だけ

変えたのは **損切りを何の値幅で測るか** です。

| 足 | ATR中央値（終値比） | 損切1.5ATR に対するコスト比 |
|-----|--------------------|---------------------------|
| 1h（これまでの全217本） | 0.53〜0.69% | **14.5〜19.0%** |
| **1d（SH-01）** | **3.15〜3.94%** | **2.5〜3.2%** |

往復コストは元本の 0.150% で固定です。分母を大きくする以外に比率は下がりません。
**1時間ATRで損切りしていた間、毎トレード R の15〜19%をコストに払っていました。**
217本が「わずかにプラス／わずかにマイナス」を往復していたのは、これが理由です。

シグナルの中身は Donchian 突破という、この上なく平凡なものです。
新しい発見をしたのではなく、**平凡なものが機能する土俵に移した**だけです。

### 回数の問題はゲートを緩めずに解いた

日足規模は1銘柄では年20〜40回しか発火せず `min_trades=100` に届きません。
EH-07 で2回先送りしてきた論点です。今回は **6銘柄を事前宣言して合計で稼ぐ**方法を取りました。
ゲートもコストも一切緩めていません。副産物として「別の銘柄でも効くか」の検証にもなります。

## 3. 買い持ちとの比較 — ここが本題

上昇相場でトレンド追随が儲かるのは当たり前なので、**買い持ちと比べて意味があるか**を見ます。

| 期間 | 買い持ち（等加重・無レバ） | 買い持ちDD | `sh01_tp_4atr` | 戦略DD | 上回った変種 |
|------|---------------------------|-----------|----------------|--------|-------------|
| Set A 2023 | **+217.7%** | 30.4% | +32.4% | 14.4% | 0 / 23 |
| Set B 2024 | **+144.0%** | 42.6% | +28.4% | 13.9% | 0 / 23 |
| Set C 2025-26 | **−33.1%** | 64.2% | **+38.0%** | 18.9% | **23 / 23** |

読み方はこうです。

- **上げ相場では買い持ちに完敗する。** 当然で、損切りを置いて部分的にしか張らないため
- **下げ相場で反転する。** バスケットが3分の1減った期間に +38%、DDは64%に対して19%
- レバレッジ買い持ちならここで壊滅します。**そうなっていない**ことが、ベータではない証拠

つまりこれは「相場より儲かる仕組み」ではなく、**「相場の方向に依存しない仕組み」**です。
運用目的（証拠金を溶かさずに増やす）には後者のほうが合っています。

## 4. 反証テスト — 先読みではないか

これだけ結果が変わると、まず自分のコードを疑うべきです。
シグナルを丸ごと遅らせて、それでも残るかを見ました。

| | EV(A) | EV(B) | EV(C) |
|---|-----|-----|-----|
| 基準線 | +2.760 | +3.120 | +0.380 |
| 1時間遅らせる | +2.481 | +2.915 | +0.431 |
| **1日遅らせる** | **+1.970** | **+3.200** | **+0.243** |
| 3期間PASS版を1日遅らせる | +0.355 | +0.931 | +0.321 |

**1日遅らせても3期間すべてでプラス**です。減衰はしますが消えません。
瞬間の情報に依存していない＝実装上の先読みではない、と判断します。

（バックテストエンジンは前バーのシグナルで次バー始値に入る作りで、
チャネルは完了した日足のみ、遅い足の終値は完了バーのみを参照しています。）

## 5. EH-06 拒否フィルタは効かなかった

3期間で向きの情報が確認されていた EH-06 の乖離を、
「群衆と同じ側に立つ取引を拒否する」フィルタとして載せました。結果は明確です。

| | EV(A) | EV(B) | EV(C) |
|---|-----|-----|-----|
| 基準線 | +2.760 | +3.120 | +0.380 |
| 拒否フィルタ（符号のみ） | +2.608 | +3.113 | +0.312 |
| 拒否フィルタ（1.0σ） | +2.555 | +2.893 | +0.343 |

**3期間とも、わずかに悪化します。** 向きに情報があることと、
トレンド追随の入口を改善することは別でした。

理由は測ってみて分かりました。突破が起きる場面では、
そもそも群衆は上位トレーダーほど買っていない（乖離がマイナス側に寄る）ため、
拒否フィルタがほとんど発火しません。1.0σでは6銘柄・1年で数件しか止まらない。
**EH-06 はここでも採用しません。**

---

## 6. まだ採用と言えない理由

1. **23本は23回の独立試行ではない。** 全部が「トレンド継続」という1つの機構を共有しています。
   実質的な試行回数は1に近い
2. **ゲートを通ったのは1本だけ。** 系統はプラスでも、`min_trades` と DD 20% の両方を
   3期間で満たしたのは `tp_4atr` のみ。しかもこの設定は EV が系統内で最も低い
   （回数を増やしてDDを下げる代わりに1回あたりを削っている）
3. **`tp_4atr` は固定利確。** これまで「固定利確は大勝ちを切る」と繰り返し学んできた形です。
   にもかかわらずゲートを通ったのは、**ゲートがDDと回数を要求しているから**であって、
   EV が最大だからではありません。ゲートの設計が答えを選んでいる可能性があります
4. **3期間とも暗号資産の同じ大相場の一部**です。独立とは言えません
5. **DD 18.9% は上限20%にかなり近い**。銘柄構成が変われば超える

## 7. 次にやること

1. **`tp_4atr` が本当に最良かを疑う。** ゲートの3条件（EV>0 / n≥100 / DD≤20%）のうち、
   何が効いて他の変種を落としているかを分解する。DDが原因なら、
   同時保有数の制限やポジションサイズの調整で系統全体が通る可能性がある
2. **近傍を地図にする。** 利確倍率・入口日数・退出日数の3軸で、傾斜か一点かを確認する
   （EH-06N で確立した手順）
3. **銘柄を入れ替えて検証する。** 事前宣言した6銘柄以外（LTC / DOT / AVAX / LINK など）で
   同じ設定を回す。機構なら効くはず
4. **EH-06 拒否フィルタは打ち止め**

やらないこと: パラメータの再最適化、`tp_4atr` の単体採用、銘柄構成を結果に合わせて変えること。
