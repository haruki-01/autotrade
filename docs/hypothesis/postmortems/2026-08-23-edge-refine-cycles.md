## 2. フェーズ1 — EH-01R（退出と建て方）

入口条件（24h突破＋OI増0.5%/4h）を1文字も変えず、退出と建て方だけを24通り動かしました。

### 何が起きたか

Set B で3本がゲートを通り（`entry_confirm` +0.013 / `brk192_trail_4` +0.063 / `brk192_retest` +0.005）、
**Set C では3本とも不合格**でした（−0.069 / −0.022 / −0.035）。

自分の基準線との差を両期間で見ると、一貫していたのはこれだけです。

| ノブ | ΔEV(B) | ΔEV(C) | 判定 |
|------|--------|--------|------|
| `trail_off`（トレールなし・構造退出のみ） | +0.002 | +0.058 | **両期間で改善** |
| `trail_4`（トレール4ATR） | +0.009 | +0.010 | **両期間で改善** |
| `trail_1p5`（トレール1.5ATR） | −0.121 | −0.116 | 両期間で悪化 |

### 読み取り

**ATRトレール2.5倍は勝ちトレードを切っていました。** 緩めるか外すと両期間で改善します。
これは「固定利確が大勝ちを切る」という v1 の敗因と同じ構造で、トレールでも同じことが
起きていたということです。今後の既定値は **構造退出のみ、またはトレール4以上** にします。

一方で、**入口の建て方（1本後の確認・遅延・戻り待ち）はすべて不安定**でした。
Set B では改善に見えても Set C で反転します。特に遅延と戻り待ちは Set C で明確に悪化
（delay_8 −0.121、retest −0.070）しており、**突破に対して待つのは損** という方向です。

そして退出をどう変えても、EV は −0.10 〜 +0.06 の帯から出ませんでした。
**EH-01 のボトルネックは退出ではありません。** 入口条件そのものを変える必要があります。

## 3. フェーズ2 — EH-07R（洗浄後の入り方）

「OIが急減した後に元の方向へ戻る」の、入り方を4通りに作り直しました
（2本遅延／値動きが落ち着いてから／ショック前水準の取り戻し／建玉の積み直し）。

### 何が起きたか

ゲート合格は0本。**ただし全163本で唯一、両期間ともEVがプラスだった変種があります。**

| logic | nB | EV(B) | nC | EV(C) |
|-------|----|-------|----|-------|
| `eh07r_oi_rebuild_pre48` | 59 | +0.225 | 79 | +0.058 |

（元方向を48時間で判定し、建玉が積み直され始めたら入る）

一方、回数を稼ぐために洗浄の閾値を緩めた版は **両期間で悪化** しました。

| ノブ | ΔEV(B) | ΔEV(C) |
|------|--------|--------|
| `hifreq_reclaim`（OI急減0.3%・値幅1.2ATR） | −0.023 | −0.135 |
| `hifreq_rebuild` | −0.013 | −0.152 |
| `hifreq_delay` | −0.022 | −0.088 |

### 読み取り

**清算洗浄のエッジは本物だが、スケールしません。** 大きな洗浄は年に50〜80回しか起きず、
小さな洗浄まで拾うとエッジが消えます。`min_trades=100` を満たす形にした瞬間に負けます。

これは「ゲートを緩めるか、希少エッジを諦めるか」という前から続く論点そのものです。
今回はデータで挟み撃ちにできました。**回数を増やす方向の改良はもう試しません。**

## 4. フェーズ3 — EH-02R（現物先行の測り直し）

100サイクルで効果量が最大（対照比 +0.355 / +0.549）だったのに n=39 で判定できなかった仮説です。
測り方を3通り（リターン差のz / 累積乖離 / スプレッド変化）に作り直し、
単独の引き金ではなく **頻度のある突破へのゲート** として使いました。

### 何が起きたか

頻度の問題は解決しました。シグナルは年89 → 526に増え、トレードは n=309（B）/ 525（C）。

そして **全18本が両期間でマイナス** でした。決定的なのはこれです。

| 比較 | ΔEV(B) | ΔEV(C) | 判定 |
|------|--------|--------|------|
| `ctrl_no_gate`（ゲートなし）− base | +0.018 | +0.044 | **ゲートを外したほうが良い（両期間）** |

測り方を変えても（累積・スプレッド）結果は同じでした。

### 読み取り

**EH-02 は棄却します。** 100サイクルで見えた大きな効果量は、n=39 の小標本による見かけでした。
十分な回数で測り直すと、現物先行ゲートは **むしろ成績を落とします**。

これは今回いちばん価値のある否定です。効果量が大きく理屈も通っていたので、
測り直さなければ「有望な仮説」として残り続けていました。

---

## 5. 制度上の学び

1. **小標本の大きな効果量は、優先的に潰す対象。** 有望に見えるものほど早く n を増やして測り直す。
   EH-02 は「n が足りない」ではなく「n を増やしたら消えた」だった
2. **改良は基準線との差で見る。** 絶対EVだけ見ていたら EH-01R の3本を採用しかけた
3. **トレールも利確と同じ罠。** 固定利確を外したのに、トレールを締めて同じことをしていた
4. **回数を増やす改良には、エッジを薄める副作用がある。** EH-07R で両期間一致して観測された

## 6. 次にやること

順番に実施した3つは、いずれも「そのまま採用」には至りませんでした。次は方向を変えます。

1. **EH-01 は入口条件を変える。** 退出は打ち止め。OIの測り方（増加率ではなく建玉の
   相対水準・増加の持続性）に手を入れる。既定の退出は **構造退出のみ / トレール4以上**
2. **EH-07 は `min_trades` の議論に載せる。** 年60〜80回で両期間プラスという結果は、
   ゲートを変えるか複数銘柄に広げるかの判断材料。**ロジック側の改良は打ち止め**
3. **EH-02 は棄却。再探索しない**
4. **EH-06 / EH-09 は未着手。** 100サイクルで機構が再現した残り2つ

やらないこと: EH-01R/EH-07R/EH-02R の同値パラメータ再最適化、Set B PASS のみを根拠にした採用。
