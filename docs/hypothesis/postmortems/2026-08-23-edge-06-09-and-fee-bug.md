## 1. 結論（先に）

このフェーズの成果は3つで、重要な順に並べるとこうなります。

1. **検証基盤にバグがありました。** エントリー手数料が損益計算から抜けていて、
   これまでの全評価で EV が1トレードあたり約 **+0.05 USDT 過大**に出ていました。
   修正済みです。過去の「Set B PASS」の多くは、実際には負けです。
2. **EH-09（吸収）は棄却。** 2023年（Set A）では20本すべてマイナスで、
   対照のほうが良いという逆転まで起きました。機構は再現していません。
3. **EH-06（個人と上位の乖離）は、向きだけが本物。** 符号を反転した対照との差は
   3期間すべてでプラス（+0.13 / +0.06 / +0.01、絞り込み後は +0.30 / +0.48 / +0.22）。
   ただし水準がコストを超えず、**採用可能な変種は0本**です。

**3期間すべてでゲートを通ったロジックは、54本中0本です。**

---

## 2. 最重要 — 手数料の二重計上ではなく「片道の抜け落ち」

`run_backtest` はエントリー時に手数料を equity から引き、決済時の `Trade.pnl` は
**決済側の手数料しか引いていません**でした。equity カーブは正しく、1トレードあたり損益だけが
片道分だけ良く出ていた、という形です。ゲートの `expectancy` はこの `pnl` の平均を見ています。

数字で言うと、想定元本 90 USDT に対して片道 0.055% = **0.0495 USDT**。
これは今回測っていたエッジ（EV +0.006 〜 +0.23）と同じオーダーです。

実例（`eh06n_center` / Set C、n=148）:

| | 修正前 | 修正後 |
|---|--------|--------|
| EV（1トレードあたり） | **+0.006** | **−0.043** |
| ゲート判定 | PASS | FAIL |
| 総リターン | −2.12% | −2.12%（変わらず） |

修正前は「EV はプラスなのに資産は減る」という矛盾が出ていました。今は
`sum(pnl)` と equity の増減が完全に一致します。

### 影響範囲

このブランチの EH 系 formal eval は累計217本、それ以前の double-bottom や
h4_spots の評価も同じエンジンを使っています。**すべての EV が約 +0.05 過大でした。**

救いは、これまでの結論がすべて「採用せず」だったことです。修正は成績を悪くする方向なので、
**過去の否定的な結論はそのまま成立します**。逆に言えば、これまで何度も見た
「ゲートすれすれでプラス」は、多くが実際にはマイナスだったということです。

## 3. コストの床 — なぜ「すれすれ」ばかりだったのか

修正して初めて、問題の形がはっきりしました。

| 項目 | 金額 | 元本比 |
|------|------|--------|
| 想定元本（証拠金30 × レバ3） | 90.00 USDT | — |
| 手数料（往復 0.055% × 2） | 0.0990 USDT | 0.110% |
| スリッページ（往復 0.02% × 2） | 0.0360 USDT | 0.040% |
| **1トレードのコスト合計** | **0.1350 USDT** | **0.150%** |

1トレードの許容損失は 3 USDT なので、**コストは許容損失の 4.5%** です。
つまり毎回 0.045R を先払いしてから勝負している。

今回測ったエッジの生の大きさは 0.05〜0.25 USDT で、**コストと同じオーダー**です。
これがこの数か月ずっと「わずかにプラス／わずかにマイナス」を行き来していた理由です。
戦略の良し悪し以前に、**この口座サイズと保有時間の組合せでは、コストが信号と同じ大きさ**でした。

出口は2つしかありません。1トレードあたりの値幅を大きくする（＝保有を長くする）か、
元本あたりのコスト比率を下げる（＝1回の元本を大きくする）か。
どちらも「もっと良いシグナルを探す」とは別の話です。

## 4. EH-09R（吸収）— Set A で棄却

高値を更新しているのに成行買いが減る＝吸収、という仮説です。
改良は2方向で、成行比の測り方を metrics の集計値から**先物出来高のテイカー買い比率**に
置き換える版と、退出を前フェーズの学び（構造退出・トレール4以上）に合わせる版を用意しました。

### 何が起きたか

Set B では20本中7本がゲートを通り、これまでで最も良く見えました。
Set C でも符号は保たれていました。**そして Set A（2023年）で全滅しました。**

| 期間 | ゲート合格 | EV>0 の本数 |
|------|-----------|-------------|
| Set A (2023) | 0/20 | **0/20** |
| Set B (2024) | 7/20 | 13/20 |
| Set C (2025-26) | 0/20 | 0/20 |

決定的なのは対照との差です。

| 比較 | ΔEV(A) | ΔEV(B) | ΔEV(C) |
|------|--------|--------|--------|
| 吸収 − 順張り対照 | **−0.050** | +0.121 | +0.065 |
| 出来高版 − 順張り対照 | **−0.080** | +0.193 | +0.100 |

2023年では**成行の減衰に逆らうより、素直に付いたほうが良かった**。
100サイクルで「機構が再現した」と判定したのは、B と C の2期間しか見ていなかったからです。

### 読み取り

**EH-09 は棄却します。** 吸収の効果は2024年に強く出た局面依存の現象で、
2023年には逆向きでした。測り方を変えても（出来高版でも）同じ結論です。

## 5. EH-06R / EH-06N（個人と上位の乖離）— 向きは本物、水準が足りない

個人勢と上位トレーダーのポジションが逆を向いたら上位側に付く、という仮説です。
100サイクルでは機構が再現したものの、年800〜1200回という回転と最大DD 51% が問題でした。
改良はまず**回転を落とす方向**（クールダウン・持続要求・突破のゲート化）と、
退出の作り直しで20本。

### 何が起きたか

Set B で `cool96_thr2`（乖離2.0σ以上 + 24時間クールダウン）が突出しました。
ところが**クールダウン単独も閾値単独も3期間すべてマイナス**で、組合せだけが効いている。
これは過剰適合のいちばん典型的な形なので、近傍を14本で地図にしました（EH-06N）。

結果、**スパイクではなく傾斜**でした。

| 閾値（クールダウン24h固定） | EV(A) | EV(B) | EV(C) |
|------|-------|-------|-------|
| 1.5σ | −0.018 | −0.164 | −0.232 |
| 1.75σ | +0.022 | −0.053 | −0.240 |
| 2.0σ | +0.045 | +0.185 | −0.043 |
| 2.25σ | +0.091 | +0.067 | −0.074 |
| 2.5σ | +0.134 | +0.307 | −0.052 |

| クールダウン（閾値2.0σ固定） | EV(A) | EV(B) | EV(C) |
|------|-------|-------|-------|
| 12h | −0.000 | +0.085 | −0.073 |
| 16h | −0.002 | +0.164 | −0.067 |
| 24h | +0.045 | +0.185 | −0.043 |
| 32h | +0.044 | +0.106 | −0.024 |
| 48h | +0.014 | +0.269 | +0.006 |

どちらも単調です。**極端なほど良く、間を空けるほど良い。** 偶然の一点ではありません。

そして符号反転の対照は、3期間すべてで大きくマイナスでした。

| | EV(A) | EV(B) | EV(C) |
|---|-------|-------|-------|
| 上位側に付く（`center`） | +0.045 | +0.185 | −0.043 |
| **個人側に付く（対照）** | **−0.254** | **−0.292** | **−0.259** |
| 差 | +0.299 | +0.476 | +0.216 |

### 読み取り

**乖離の向きには3期間を通じて本物の情報があります。** 逆に張れば確実に負ける、
という意味で機構は成立している。今回の全217本で、これだけが3期間で一貫しました。

**ただし採用はできません。** 上位側に付いても、2025-26年（Set C）では EV がマイナスです。
「損を減らす」効果は 0.22〜0.48 USDT/トレードとコストの2〜3倍あるのに、
**その効果を足した後の水準がゼロ近辺**にとどまる。つまりこの乖離は、
それ単独で入る理由にはならないが、**入る／入らないを決める材料としては効いている**。

3期間ともEVがプラスだったのは `eh06n_cool_192`（+0.014 / +0.269 / +0.006）1本だけですが、
A で n=92、B で n=73 と `min_trades=100` に届かず、A と C の EV はノイズと区別できません。

## 6. 制度上の学び

1. **バックテスト基盤そのものを疑う番が来ていた。** 「EV はプラスなのに資産が減る」を
   217本のあいだ見過ごしていた。今後、EV の合計と equity の増減が一致することを
   レポート生成時に検算する
2. **2期間では足りない。** EH-09 は B と C で機構が再現していたが、A で逆転した。
   Set B は探索に使い、Set C も何度も見た。**未使用の期間を必ず1つ残す**
3. **組合せだけが効くときは、近傍を地図にする。** 今回は傾斜だったので機構は残ったが、
   同じ検査でスパイクなら即座に捨てられた。この手順を標準にする
4. **コストと信号が同じオーダーなら、シグナル探しは無駄。** 先に構造（保有時間・元本）を
   決めるべきだった

## 7. 次にやること

シグナル探索を続ける前に、**コストの床**に手を付けます。これが今回いちばんはっきりした話です。

1. **保有時間を伸ばす方向で設計し直す。** 現在の 15m 実行・平均数時間保有では、
   1トレードのコスト 0.15% に対して値幅が足りない。日足〜4時間足の値幅を取る形に変える
2. **EH-06 の乖離は「入る理由」ではなく「入らない理由」として使う。**
   単独ロジックとしては打ち止め。別の引き金に対する拒否フィルタとして再設計する
3. **EH-09 は棄却。再探索しない**
4. **レポート生成に検算を入れる。** `sum(trade.pnl) == final_equity - initial_equity` を
   全ランで assert する

やらないこと: EH-06/EH-09 の同値パラメータ再最適化、2期間だけを根拠にした採用、
コスト構造を変えないままの新規シグナル探索。
