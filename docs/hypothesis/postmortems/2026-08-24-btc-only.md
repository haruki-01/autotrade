# BTC-USDT 単独に絞ると何が残るか

date: 2026-08-24
対象: SH-01 / SH-01N（低速トレンド継続）
指示: 銘柄を BTC-USDT のみに絞る
関連: [宣言外追試と再現性](./2026-08-24-slow-oos-and-reproducibility.md) · [SLOW_HYPOTHESES](../SLOW_HYPOTHESES.md)

## 結論を先に

1. **機構は BTC 単独でも残る。** 全履歴3期間で 42通り中41通りが EV プラス。
   プール後 `sh01n_center` は n=164 / EV +0.989 / **t = +2.57**。1日遅らせても3期間プラス。
2. **ただし期間ごとには証明できない。** 1期間 n≈55 では t = +2.78 / +0.80 / +0.72 で、
   Set A 以外は有意でない。`min_trades=100` は**1銘柄では原理的に到達不能**。
3. **そして BTC を持っているだけの方が儲かる。** 上昇した2期間では生リターンで
   14本すべてが買い持ちに負ける（Set C は −72pt）。リスク調整後（リターン÷DD）でも
   直近 Set C は 14本中12本が買い持ちに負けます。
4. **絞ったことで、SH-01 が良く見えていた理由が消えた。** 6銘柄版が買い持ちを
   60〜80pt 上回っていたのは、崩れたアルトをショートできたからです。BTC 単独にその機会はありません。

**現状の判定: BTC-USDT 単独では採用できません。** 宣言ゲートに届かず、
買い持ちに対する優位もDDだけです。

---

## 1. まず素直に絞ってみた

v2 の期間（1〜1.6年）で BTC だけを回した結果です。

| | Set A (2023) | Set B (2024) | Set C (2025-26.8) |
|---|---|---|---|
| n（中心設定） | 22 | 26 | 31 |
| EV | +0.715 | +0.450 | +0.534 |

符号は3期間ともプラスですが、**n が 15〜43**。`min_trades=100` に対して全変種が
トレード数で落ちます。日足規模のロジックは BTC 単独で年20〜25回しか発火しないので、
1年の期間では構造的に無理です。

## 2. 期間を伸ばす（`configs/eval_v3_btc.yaml`）

回数を稼ぐ手段が銘柄から期間に変わっただけです。Binance に BTCUSDT の15分足がある
全範囲を、ほぼ等長の3期間に割りました（ウォームアップ400日を確保して 2018-10 から）。

| 期間 | 範囲 | 年数 |
|---|---|---|
| Set A | 2018-10-01 〜 2021-04-30 | 2.58 |
| Set B | 2021-05-01 〜 2023-12-31 | 2.67 |
| Set C | 2024-01-01 〜 2026-08-22 | 2.64 |

結果（中心設定 `sh01n_center`）:

| | Set A | Set B | Set C | プール |
|---|---|---|---|---|
| n | 56 | 51 | 57 | **164** |
| EV | **+1.951** | +0.528 | +0.456 | **+0.989** |
| t | +2.78 | +0.80 | +0.72 | **+2.57** |
| 最大DD | 2.8% | 5.3% | 7.6% | — |

近傍14本で **42通り中41通りが EV プラス**（唯一のマイナスは利確を近づけた `tp_2`）。
プール後に t ≥ 2 が 12/14。DD は全期間で 2.4〜12% と非常に小さい。

反証（`sh01_tp4_delay_1d`、シグナルを1日遅らせる）:

| | Set A | Set B | Set C |
|---|---|---|---|
| 基準 | +1.951 | +0.528 | +0.456 |
| 1日遅延 | +1.257 | +0.333 | +0.320 |

減衰しますが3期間とも消えません。実装上の先読みではありません。

### `min_trades=100` は妥当だった

「1銘柄では届かないからゲートを下げる」は、答えを通すために物差しを動かす行為です。
代わりに、**各変種のばらつきから必要トレード数を逆算**しました。

t = EV / (sd/√n) なので、t = 2 に必要な n は (2·sd/EV)²。

| 変種 | プール n | EV | sd | t | 必要 n |
|---|---|---|---|---|---|
| `sh01n_tp_8` | 127 | +1.807 | 6.79 | +3.00 | **56** |
| `sh01n_tp_6` | 143 | +1.388 | 6.07 | +2.73 | **77** |
| `sh01n_center` | 164 | +0.989 | 4.94 | +2.57 | **100** |
| `sh01n_tp_2` | 210 | +0.197 | 3.36 | +0.85 | 1163 |

中心設定でちょうど 100。**ゲートの 100 は誰かが決めた数ではなく、この戦略の
ばらつきが要求する数でした。** 下げる理由はありません。

言い換えると、**1期間 n≈55 は「まだ判定できない」という意味**で、
プール後の n=164 / t=+2.57 が現時点で言える最良の推定です。
ただしプールは3つの異なる相場を1つに混ぜているので、期間ごとの合否より弱い証拠です。

## 3. 買い持ちと比べる — ここが本題

生リターンは投下資本が違う分だけ戦略に不利です（`fixed_margin` は1銘柄あたり
証拠金 30 / 元本 300 しか使わない）。`fixed_margin` はリスク額を k 倍すると
リターンもDDもほぼ k 倍になるので、**リターン ÷ DD** が資本量に依らない比較になります。

| | Set A | Set B | Set C |
|---|---|---|---|
| BTC 買い持ち | **+768.9%**（DD 72.2%） | −27.1%（DD 77.2%） | **+81.4%**（DD 53.8%） |
| 中心設定 | +36.4%（DD 2.8%） | +9.0%（DD 5.3%） | +8.7%（DD 7.6%） |
| ret/DD 戦略 | +13.02 | +1.69 | +1.14 |
| ret/DD 買い持ち | +10.65 | −0.35 | **+1.51** |
| 生リターンで勝った変種 | 0/14 | 14/14 | 0/14 |
| ret/DD で勝った変種 | 7/14 | 13/14 | **2/14** |

読み方:

- **下落期（Set B）は圧勝。** 買い持ち −27% に対して +9%、DD は 77% 対 5%
- **上昇期は負ける。** 生リターンでは全敗。ret/DD でも直近 Set C は 12/14 が負け
- 戦略の取り分は「BTC が上がった分の一部」で、下げでは減らない。
  つまり**売っているのはリターンではなくDD**です

### 6銘柄版と何が違ったのか

| Set C | 6銘柄 | BTC単独 |
|---|---|---|
| 戦略リターン | +43.4% | +8.7% |
| 買い持ち | **−33.1%** | **+81.4%** |
| 差 | +76.5pt | −72.7pt |

同じロジック・同じ期間で、符号が反転します。6銘柄版が買い持ちを大きく上回っていたのは、
**2024〜2026年に崩れたアルト（DOGE・XRP・SOL）をショートで取れたから**でした。
BTC 単独にその機会はなく、BTC はただ上がったので、追随して一部を取るしかありません。

**「SH-01 は買い持ちに勝つ」は6銘柄版の性質で、ロジックの性質ではありませんでした。**

## 4. いま言えること／言えないこと

言えること:

- 日足規模・日足ATR損切りという**コスト設計は正しい**。BTC 単独でもプール t=+2.57
- 機構は先読みではない（1日遅延で残る）
- **DD が極端に小さい**（2.4〜12% 対 買い持ち 53〜77%）

言えないこと:

- 期間ごとの合否（n が足りない。1銘柄では到達不能）
- 買い持ちを超えるリターン（上昇期は負ける。直近はリスク調整後でも負ける）
- EV の水準の維持。+1.951 → +0.528 → +0.456 と**時間とともに落ちています**

## 5. 次の選択肢

**A. レバレッジ／投下資本の設計に進む**
DD 7.6% 対 買い持ち 53.8% は、**同じDDまで張れば買い持ちを超える**余地が
6倍あることを意味します（Set C: 8.7% × 6 ≒ +52% 対 +81% なのでまだ足りない。
Set A・B なら超える）。ただし Set C で足りないなら「直近では負ける」が結論です。
`max_concurrent_positions: 1` と `margin_per_trade: 30` の設計を見直す話。

**B. BTC 単独で回数を増やす**
4時間足規模へ落として年50〜100回にする。ただしコスト比が 2.5% → 6.8〜8.6% に上がるので、
コストの床の議論に戻ります。中間点として測る価値はあります。

**C. DD を売り物と割り切って採用する**
リターンでは買い持ちに負けるが、DD 1/7 で年数%を取る器として運用する。
レバレッジをかける前提なら意味のある選択です。

**D. 打ち止め**

推奨は **A**。「BTC 単独 + 日足規模」で残っている優位はDDだけなので、
それを金額に変えるにはサイジングを触るしかありません。
シグナルをこれ以上探しても、この構造は変わりません。
