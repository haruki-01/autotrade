# 1H × 上位上昇 × 鮮度 × 高値奪還

## CLAIM

ダブルボトムのネック再テストで、**日足上昇構造中だけ**・**突破後48時間以内**・**突破時高値を奪還した反発**で入ると、費用後期待値がプラスになりやすい。

## WHY

20サイクルで質が良かった測り方（上昇のみ / 鮮度 / 高値奪還）を、回数を確保できる1H構造に移植する。  
DB-20（1H×上昇×高%戻し）は EV マイナスだったため、反発定義を **高値奪還** に差し替える（同値再チューニングではなく、別ノブの合成）。

## WHO LOSES

突破直後の追いかけ買い、古い突破への遅い再テスト、下降構造での逆張り的ロング。

## DIES WHEN

Set B で EV≤0 または DD>20%。PASSでも Set C で符号が崩れたら棄却。

## 最小ルール

| 部品 | 定義 |
|------|------|
| 構造足 | 1H（執行15m、1m未満禁止） |
| ダブルボトム | ピボット安値2点が ATR×0.6 以内 |
| 突破 | 1H終値 > ネック |
| 鮮度 | 突破後 **48本（≈48h）** 以内の再テストのみ |
| 反発 | 終値が突破時の高値を超える（奪還） |
| 上位 | 日足スイングが上昇構造のみ |
| 損切 | ネック帯割れ相当 |
