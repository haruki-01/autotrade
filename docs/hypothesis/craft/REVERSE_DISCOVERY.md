# 仮説の作り方②：過去データ逆算ディスカバリ

**別ファイル管理。**  
チャート定番から①を書く方法（CATALOG / DEEP_COMPOSITE）とは逆に、

> 過去の値動きから「このあと伸びた局面」を集め → 直前に共通する条件を見つける → 同じ条件を今後もエントリー仮説にする

という作り方。

---

## 1. 位置づけ（三層との関係）

```text
過去データ
  → 「大きく伸びた／大きく落ちた」結果局面を集める
  → 直前特徴を集約（複合条件の芽）
  → ① トレードスポット仮説（データ由来）
  → ② 実証ロジック化
  → ③ 未使用期間で formal eval（発見に使った期間では合否を出さない）
```

**重要:** 発見に使った期間で「勝てた」はまだ検証ではない。  
発見セットと検証セットを分ける（本リポでは目安: 発見=2022–2023 / 検証=Set B 2024）。

---

## 2. 手順（再現可能なプロトコル）

### R0 — 期間ロック

| 役割 | 期間例 | 用途 |
|------|--------|------|
| Discovery | 2022-05-26 → 2023-12-31 | パターン探索のみ |
| Holdout validation | 2024-01-01 → 2024-12-31 | formal eval のみ（探索禁止） |

### R1 — 「良い結果」のラベル（アウトカム）

例（ロング）:

- エントリー想定バーの終値から **H日後** のリターン ≥ **τ**（費用＋余裕、例: 10日で +2%以上）
- または、期間内リターン分布の上位X%

ショートは符号反転で同様。  
ラベルは **未来情報を特徴に入れない**（特徴はエントリー時点まで）。

### R2 — 直前特徴（複合の素材）

価格だけで作れる例:

- トレンド: 終値 vs SMA50/200、HH/HL 近似
- 位置: N日高値/安値からの距離、レンジ内位置
- ボラ: ATR%、ATRの変化（圧縮/拡大）
- 直近の成否: N日ブレイクの有無、ブレイク後の戻り率
- 時間: 曜日、UTC時間帯（足による）
- 連続性: 連騰日数、押しの深さ（直近スイング比）

### R3 — 逆算の仕方（3系統）

**系統A — 成功局面のプロファイル**

1. アウトカム成功バーだけ集める  
2. 各特徴の分布を「全バー」と比較  
3. 成功に偏って多い条件をリスト化  
4. 条件を2〜4個束ねて①の文にする  

**系統B — 条件グリッドの前向きスコア（探索）**

1. 単純な複合条件を列挙（事前にリスト固定・無限探索しない）  
2. Discovery期間だけで前方リターン平均・中央値・n・費用超え率を出す  
3. nが足りる・費用を超えそうな束だけ残す  
4. ①に昇格（Holdoutではまだ触らない）

**系統C — 大きな伸び局面からの逆算（今回拡張）**

1. Forward リターンまたは MFE の上位X%を「大きく伸びた局面」とラベル  
2. その直前バーの特徴偏りを全日と比較  
3. 正の偏りが大きい特徴を束ねて①にする  
4. 負の偏り（例: アジア薄い時間）は「撃たないゲート」候補  

**足の拡張:** 日足に加え **4H** で同じ系統B/Cを回す（イベント頻度・セッション特徴のため）。

### R4 — ①への文章化

データで見えたことを、インジ名の羅列ではなく場面の言葉にする。

悪い例: 「ATR<x かつ close>SMA50 かつ …」だけ  
良い例: 「値幅が縮んだあと、中期上昇のまま高値付近で再挑戦した局面は上に伸びやすかった。市場は縮みブレイクの初動ばかり見るが、再挑戦の方が偏っていた。」

### R5 — ②③へ

- ②: 特徴を再現するロジックを1〜2通り  
- ③: **Holdout のみ** formal eval  
- Discovery で切った閾値を Holdout で再最適化しない  

---

## 3. やってはいけないこと

| NG | 理由 |
|----|------|
| 全期間で探索して同じ期間で合否 | 完全なデータスヌーピング |
| 特徴を何百も自動探索して最良だけ報告 | 多重検定 |
| 発見結果を「検証済みエッジ」と呼ぶ | ③前 |
| 未来足の高値安値を特徴に入れる | ルックアヘッド |

## 5. コマンド

```bash
PYTHONPATH=src python3 scripts/reverse_discover_spots.py
```

Discovery 期間の統計だけ出す。Set B での合否は出さない。
