# 研究衛生ルール（Research Hygiene）

**これは「勝てる仮説の発想法」ではない。**  
トレードスポット仮説（①）とロジック（②）を壊さないための規律・ルール集。

筋のいい①の作り方 → [TRADE_SPOT_HYPOTHESIS.md](./TRADE_SPOT_HYPOTHESIS.md)  
三層モデル → [THREE_LAYER_MODEL.md](./THREE_LAYER_MODEL.md)

---

## この文書が守ること

| ルール | 目的 |
|--------|------|
| Who loses / 死ぬ条件を書く | パターンとエッジを混同しない |
| 自由度 ≤1 / 試行番号 | 多重検定・選択バイアス |
| ready 前に eval しない | 作成と検証の混線防止 |
| lock・実データ・固定コスト | 再現性 |
| 1ロジック1変更 | 何が効いたか分かる |
| FAIL も残す | 同じ失敗を繰り返さない |
| ゲート仮説は単体で先に書く | AND山を防ぐ |

**守っても①（ダブルボトム型のスポット）は自動生成されない。**

旧称「HYPOTHESIS_STOCK_METHODS」の A〜N は、上記の衛生・補充オペとしてここに吸収する。  
スポット発想そのものは `TRADE_SPOT_HYPOTHESIS.md` §3 を使う。

---

## いつ使うか

- ①を書いた**あと**、②に落とすとき  
- ②を ready にするとき（CREATION_FLOW）  
- ③を回すとき（VALIDATION_FLOW）  

①をゼロから考える会では、この文書よりチャート構造カタログを開く。
