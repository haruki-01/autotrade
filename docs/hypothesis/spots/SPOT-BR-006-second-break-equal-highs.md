# SPOT-BR-006: 同じ15分高値の初回は見送り、二度目の終値抜けだけ取る

status: proposed  
created: 2026-08-25  
枠: 12h / 1.00% / 1:1.5 / 上位足は確定後のみ / 1分はトリガーだけ

## 仮説（一文）

ほぼ同じ15分高値が二度以上止められたあと、初回のわずかな上抜けが失敗して水準内へ戻っている場合に限り、1分足が同じ水準を終値で明確に超える二度目は、初回より続きやすい。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定15分の高値が、近い水準で2回以上止められている（ダブルトップに近い抵抗） |
| 確認 | 一度その水準をヒゲまたは短い終値で超えたが、すぐに水準の下へ戻った（初回失敗） |
| トリガー | そのあと1分終値が、失敗した水準をはっきり超える（二度目） |
| 方向 | 上（対称で安値なら下） |
| 無効化 | 二度目もすぐ水準の内側へ戻る。三度目信仰で無限に待つこと |

## なぜそうなりそうか

- 誰が払うか: 初回ブレイクに飛びついて焼けた人。「水平はだまし」と決めつけて二度目を売った人
- 案2の「直前15分高値を毎回抜く」（HTF-002）との差: **毎回の高値更新ではなく、同じ水準を一度失敗したあとの二度目だけ**
- 深い① D-002 の15分×1分版

## 実装ロジック案（②・まだ検証しない）

### 実証①
- 15分高値が ATR の小さい帯で2回接触
- 初回: 1分が高値を超えたあと、K 本以内に水準下へ戻る
- トリガー: その後の1分終値が帯の上側を再突破
- 退出: 現行ブラケット

### 実証②
- 水準を1時間の高値（より丸見え）にする
- トリガーは1分終値の二度目突破のまま

## まだやらないこと

- 初回の上ヒゲ突破で入ること（HTF-002に近い）
- ③は選定後
