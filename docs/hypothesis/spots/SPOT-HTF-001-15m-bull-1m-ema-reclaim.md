# SPOT-HTF-001: 上位足の陽線場面で、1分がEMAへ戻して再開

status: tested-fail  
created: 2026-08-25

## 仮説（一文）

15分足が確定陽線（買いがその15分を取った）のあと、1分足が15分EMA20まで戻して再び上にクロスすると、同じ方向へ続きやすい。

## 根拠

- 場面は15分で決まる。1分は「いつ入るか」だけ
- 誰が損するか: 15分の高値で追いかけた遅行の買いが、押しで吐き出される。その吐き出しが終わったところで再開する側
- 無効化: 確定15分が陰線に変わる、15分EMAを明確に割れ続ける

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定した15分陽線（未完成の15分は使わない） |
| 確認 | 価格が15分EMA20の下に一時的に沈む |
| トリガー | 1分終値がそのEMAを上に取り戻す |
| 方向 | ロング（陰線なら逆） |
| 無効化 | 上位足の陽線が否定される、EMA割れが続く |

実証ロジック: `br_htf15_bull_pb`（近い派生: `br_htf1h_bull_pb`, `br_htf15_ema_pb`, `br_htf1h_ema_pb`）
