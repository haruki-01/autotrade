# SPOT-BR-002: アジアでできた箱を、厚い時間の1分で割る

status: superseded-weak-edge  
created: 2026-08-25  
枠: 12h / 1.00% / 1:1.5 / 上位足は確定後のみ / 1分はトリガーだけ

## 仮説（一文）

アジア時間に15分足で箱（高値・安値がはっきりしたレンジ）ができたあと、ロンドン〜NYの厚い時間に1分足がその箱の高値または安値を終値で割ると、割れた方向へ半日程度続きやすい。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | UTC 0〜8 頃の確定15分で、値幅が収まった箱（高値と安値が何度か触れられている） |
| 確認 | まだ箱の中。反対側は割っていない |
| トリガー | 流動性が厚い時間（目安 UTC 7〜16）に、1分終値が箱の高値または安値を更新 |
| 方向 | 割れた側 |
| 無効化 | 同じ半日で箱の反対側まで到達して戻る（中身が両方割れる） |

## なぜそうなりそうか

- 誰が払うか: アジアのレンジ内で逆張りしていた人。厚い時間のフローで巻き込まれる
- 見落とし: 「15分が陽線だから上」ではなく、**時間帯が変わって箱が壊れた**こと
- 伸び: アジア箱の高さ分以上。BTCなら1%超える日がある

## 実装ロジック案（②・まだ検証しない）

### 実証①
- 箱: UTC 0:00〜8:00 の確定15分の最高値・最安値
- トリガー: UTC 7:00以降、1分終値が箱高値超（ロング）または安値割れ（ショート）
- 退出: 現行ブラケット

### 実証②
- 箱の定義を「その区間の15分が N 本以上、直近平均より狭い」に限定（広いアジア日は捨てる）
- トリガーは同じ1分終値抜け

## まだやらないこと

- アジア時間中の箱の中での逆張り
- 箱が広い日まで全部撃つこと（E8）
- ③は選定後
