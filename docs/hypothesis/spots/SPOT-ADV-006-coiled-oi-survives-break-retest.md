# SPOT-ADV-006: 静かに積んだ建玉がある箱が、価格ブレイク後も建玉が残っているときだけ、箱への戻りを支えにする

status: proposed  
created: 2026-08-25  
評価軸: [MARKET_ADVANTAGE_AXES.md](../../master/MARKET_ADVANTAGE_AXES.md)

## 仮説（一文）

値動きが小さいあいだに建玉だけが増えていた箱（価格botには「ただのレンジ」）が、厚い時間に箱の外へ15分確定したあと、**建玉がブレイクで消えていなければ**、箱の縁への最初の戻りは支えになりやすい。建玉がブレイクと同時に減った場合は、カバーだけで上がった可能性があり、戻り支えは見送り。

## 市場の3層が何をするか

| 層 | この局面での行動 |
|---|---|
| 人 | 静かな箱は退屈。ブレイクで初めて「トレンド」 |
| 定番bot | 圧縮ブレイク（スクイーズ）を価格だけで撃つ。中身の建玉を見ない |
| 派生bot | 「圧縮＋OI増→ブレイク」は語られる（EH-08）。当時、通過した変種は圧縮ブレイク自体の効果で、OI蓄積の追加説明は消えた |

## 優位の本体と正直な弱さ

非認知の本命は「静か＋建玉増＝仕込み」。春希さんの「市場が気づく前」に近い。  
ただし EH-08 は **OI蓄積を足しても、残ったのはスクイーズの形** だった。  
今回の分割は「ブレイク後にOIが残っているか」（仕込みが乗ったままか、カバーで終わったか）。EH-08の「ブレイク前のOI増」そのものではない。

早期性: 箱のあいだはトレンド未認知。入口はブレイク確定後の戻りなので、速さではない。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 狭い箱が続き、箱の期間中にOIが切り上がっている |
| 確認 | 15分終値が箱の外。同時にOIが箱の期間の中央より下がっていない |
| トリガー | 1分が箱縁へ戻り、終値が箱の外 |
| 方向 | 抜け方向 |
| 無効化 | ブレイクと同時にOI急減。または箱の期間にOI増なし（ただのスクイーズ＝案2の親戚） |

## 既棄却との差

- EH-08: 事前OI増＋ブレイク同時撃ち。追加説明力が消えた
- br_squeeze: 価格圧縮だけ
- ADV-003: 抜け瞬間のOI増。こちらは「箱のあいだの蓄積が、抜けたあとも残っている」

## 実装ロジック案（②・未検証）

### 実証①
- 箱: 確定15分のATR下位帯が連続
- 蓄積: 箱の開始から終わりまでOIがネット増加
- 残存: ブレイク15分のOI ≥ 箱期間のOI中央
- 入口: 1分の箱縁リテスト
- 対照A: 蓄積なしスクイーズ（EH-08の失敗再現）
- 対照B: 蓄積ありだが残存なし（OIが抜けと一緒に減る）

### 実証②
- 残存条件だけを1点変える（中央値ではなく箱終了OI）
