# SPOT-BR-001: 上位足のスイング継続を、1分の高値更新で取る

status: proposed  
created: 2026-08-25  
枠: 12h / 1.00% / 1:1.5 / 上位足は確定後のみ / 1分はトリガーだけ

## 仮説（一文）

1時間足で高値切り上げ・安値切り上げが続いているとき、最後の押し安値を割らずに、1分足が直前の戻り高値を終値で更新すると、同じ方向へ続きやすい。

## 案2との違い

案2は「直近1本の15分が陽線」をトレンドにした。1本の色はノイズで、押し目は無作為より悪かった。ここでの場面は **スイングが2回以上つながっていること**。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定1時間足で HH→HL→HH（またはショートなら LL→LH→LL） |
| 確認 | 最後の押し安値（HL）が、まだ終値で割れていない |
| トリガー | 1分終値が、最後の戻り高値（直近スイング高値）を上に更新 |
| 方向 | 構造と同じ向き |
| 無効化 | 1時間の押し安値を終値で割る。ヒゲだけなら様子見 |

## なぜそうなりそうか

- 誰が払うか: 押し安値割れを待っていた売り、戻り高値で「終わり」と思った人
- 伸びのイメージ: 次の1時間レッグ。1.5%は12時間に収まりやすい側
- 入る場所: 高値更新の1本だけ。押しの途中では入らない

## 実装ロジック案（②・まだ検証しない）

### 実証①
- 使う足: 構造=確定1時間、トリガー=1分
- 構造: 左右3本のピボットでスイング。連続する HL のあと
- トリガー: 1分終値 > 直近確定スイング高値
- 退出: 現行ブラケット

### 実証②
- 構造足を確定15分の HH/HL にする（1時間より場面が多い）
- トリガーは同じ（1分の高値更新）
