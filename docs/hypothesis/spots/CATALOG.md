## 次の使い方

1. ここから **優先スポットを短リスト**（例: 継続系 C/B + 001）  
2. 選んだ ID ごとに詳細ファイル化（001形式）  
3. 各スポットに実証ロジック②を2案  
4. 検証③はロジック単位  

優先候補の目安（個人・低回転・データあり）:  
**001, 010, 012, 020, 030, 040, 052, 070, 100, 120**（要・後で削る）
