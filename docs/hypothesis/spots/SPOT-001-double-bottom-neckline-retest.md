# SPOT-001: ダブルボトム → ネック突破 → ネック再テスト反発

status: draft  
created: 2026-08-22

## 仮説（一文）

ダブルボトムのあとネックラインを突破し、ネックライン近くで再度反発すると、ロング方向に伸びやすい。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | ダブルボトム（近い水準の安値2つと、その間の戻り高値＝ネック候補） |
| 確認 | ネックラインの上抜け（終値または明確な突破） |
| トリガー | ネック付近への押し／戻りからの再反発 |
| 方向 | ロングに伸長しやすい |
| 無効化 | ネックを明確に割り込む、ダブルボトムの安値を更新、突破がすぐ失敗してレンジに戻る |

## なぜそうなりそうか（短く）

- ネック上の売りが一度掃けたあと、押し目で買いが入りやすい  
- 安値を割らない参加者の損切・含み益防衛が下を支えやすい  
- （任意ラベル）E1寄りの継続＋構造的な押し目

## 実装ロジック案（②・検証しない）

### 実証①（案）

- 足: 4H または 日足で構造、15m で執行  
- ボトム: スイング安値2点が許容差以内  
- ネック: 2底のあいだのスイング高値  
- 突破: 終値がネック超  
- 再反発: 価格がネック±帯に戻り、陽線または短期支え  
- 退出案: 構造安値割れ、またはトレーリング（固定小利確は仮説と矛盾しやすい）

### 実証②（案）

- ボトム/ネックを ZigZag またはピボット系で定義  
- 突破は日足終値、再テスト確認は 4H 陽線必須  
- 実証①より「遅い・少ない」測り方の比較用
