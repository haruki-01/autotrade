# SPOT-001: ダブルボトム → ネック突破 → ネック再テスト反発

status: active  
created: 2026-08-22  
updated: 2026-08-23

## 仮説（一文）

ダブルボトムのあとネックラインを突破し、ネックライン近くで再度反発すると、ロング方向に伸びやすい。

## 根拠（春希さんの主張を正とする）

- ネックを一度超えただけでは、ロングを焼きにいく一時的な押しがありうる  
- **ネックでの反発**を見てから初めて「上昇トレンド確定」とみなす  
- 誰が損するか: 突破直後に追いかけた遅れてきた買い、ネック割れで損切される側

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | ダブルボトム（近い水準の安値2つと、その間の戻り高値＝ネック） |
| 確認 | ネックラインの上抜け |
| トリガー | ネック付近への戻りからの再反発 |
| 方向 | ロング |
| 無効化 | ネック明確割れ、第2底割れ、突破後すぐレンジ戻り |

## 変数空間（網羅用・触るノブは1サイクル1点）

### A. 構造の測り方

| ID | 変数 | 候補 |
|----|------|------|
| A1 | 構造足 | 4H / 1H / 日足（**1分未満は禁止**） |
| A2 | ピボット左右幅 | 2 / 3 / 5 本 |
| A3 | 2底の許容差 | ATR×k / 価格% |
| A4 | 2底の時間間隔 | 最短〜最長バー数 |

### B. ネック突破

| ID | 変数 | 候補 |
|----|------|------|
| B1 | 突破定義 | 終値超え / ヒゲ超え / 終値+ATR余裕 |
| B2 | 突破の鮮度 | 突破後 N 本以内に再テスト必須 |

### C. ネック反発（エントリー）

| ID | 変数 | 候補 |
|----|------|------|
| C1 | タッチ帯 | ネック±ATR×k / ネック±価格% |
| C2 | 反発確定 | 陽線終値 / 固定%反発 / DB高の%戻し / 突破時の上ヒゲ高値奪還 |
| C3 | 執行足 | 構造足確定後の 15m（最短は1mまで可・本バッチは15m） |

### D. 上位軸フィルタ

| ID | 変数 | 候補 |
|----|------|------|
| D1 | 日足構造バイアス | 上昇のみ / 下降以外 / フィルタ無し |
| D2 | バイアス定義 | 高値安値切上げ（**EMA禁止**）/ 価格位置 |

### E. 無効化・退出

| ID | 変数 | 候補 |
|----|------|------|
| E1 | 損切 | 第2底割れ / ネック割れ / ATR×k |
| E2 | 利確 | 構造トレール / 固定なしATRトレール |

## 20サイクル方針

1サイクル = **仮説の測り方を1点だけ変えたロジック** → formal Set B → 知見 → 次の変数。  
EMA系は使わない。足は 1m 未満にしない。
