# SPOT-ADV-002: 1時間はまだトレンド未認定。下位の失敗下抜けが種になる

status: proposed  
created: 2026-08-25  
評価軸: [MARKET_ADVANTAGE_AXES.md](../../master/MARKET_ADVANTAGE_AXES.md)

## 仮説（一文）

1時間足では高値切り上げがまだ完成していない（レンジまたは低い高値）のに、15分または1分が直近安を少し割ってすぐ終値で取り戻したあと、その安を割った側の損切が巻き戻されると、**あとから**1時間がHLを作ってトレンドに見える。入るのは取り戻し確定後の、狩りの起点高値を1分が更新したときだけ。

## 市場の3層が何をするか

| 層 | この局面での行動 |
|---|---|
| 人 | 1時間チャートは「まだトレンドではない」。下ヒゲを見て逆張りするか、何もしない |
| 定番bot | 1時間EMA・HH完成待ちの個体は**まだオフ**。15分の安値割れでショートする個体はオン（狩りに参加） |
| 派生bot | 下抜けを「清算の始まり」と見る個体は初動を狙う。取り戻しまで待つ個体は少ない |

## 優位の本体（速さではない）

これは「市場が認知できるトレンドの早期検出」の正しい使い方。  
認知されるトレンドは **1時間のHH/HL**。それが完成する前に、15分の失敗下抜けでショートbotが燃料になる。  
**安値を割った瞬間には入らない**（速さ・狩り競争）。入るのは失敗が終値で確定したあと。

BR-005 との差: BR-005 は「1時間がすでにHL」＝認知のあと。ここは **1時間が未認定** が必須。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定1時間に、直近で明確なHHが無い（または直近高値が切り下がっている） |
| 確認 | 下位が直近安をわずかに更新したあと、その安を終値で回復 |
| トリガー | 1分終値が、スイープ開始前の小高値を更新 |
| 方向 | 取り戻し側（通常ロング。上側スイープならショート） |
| 無効化 | 取り戻せず安の下で15分が確定。または直後に1時間が反対側へ明確に割れる |

## 既棄却との差

- 案2 / HTF-001: 上位トレンド認定済みの押し目。遅めの認知のあと
- BR-005: 上位HL必須。トレンドbotと同じレジーム
- 清算初動: 取らない

## 実装ロジック案（②・未検証）

### 実証①
- 1時間: 直近 K 本で新高値なし
- スイープ: 1分安 < 直近 N 本安、その後 M 本以内に終値 > その安
- トリガー: 1分終値 > スイープ前ローカル高値
- 退出: 現行ブラケット

### 実証②
- スイープと取り戻しを確定15分だけで定義（未完成1分を使わない）
- トリガーだけ1分
