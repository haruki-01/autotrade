# SPOT-ADV-003: 同じ高値抜けでも、建玉が増えた突破だけが「新しいトレンド」

status: proposed  
created: 2026-08-25  
評価軸: [MARKET_ADVANTAGE_AXES.md](../../master/MARKET_ADVANTAGE_AXES.md)

## 仮説（一文）

15分または1時間の高値抜けは、同時に建玉（OI）が増えているときだけ継続しやすい。建玉が減りながらの抜けは、売り方の買い戻しで値が上がっているだけなので、価格botが「トレンド」と認知しても続きにくい。入るのは **OI増加側の抜けが15分で確定したあと**、1分が抜け水準を支えとして触れたとき。抜けの確定と同時の成行はしない。

## 市場の3層が何をするか

| 層 | この局面での行動 |
|---|---|
| 人 | 同じ陽線に見える。OIを見ない |
| 定番bot | 高値抜けならOIに関係なく撃つ。**ここが偽トレンドの混雑** |
| 派生bot | OIフィルタを持つ個体は増えている。ただし「抜けと同時」に撃つとまた混雑 |

## 優位の本体

市場（価格だけ）は両方を同じトレンドとして認知する。  
こちらは **認知できない分割**: 新規資金のトレンド vs ショートカバーの値動き。  
早期検知ではない。同じ時刻の同じ形を、公開OIで二群に分ける。

EH-01: 二群の差は再現したが、当時の突破ロジックは費用に届かず採用0。  
再利用してよいのは「入口の分け方」だけ。同時エントリーと固定利確の相性は未知（軸6は控えめ）。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 丸見えの高値/安値（箱またはスイング） |
| 確認 | 確定15分終値が水準を超える **かつ** その15分区間でOIが増加 |
| トリガー | その確定のあと、1分が水準付近まで戻して終値で水準の外を維持 |
| 方向 | 抜け方向。OI減少の抜けは見送り（または反対仮説にしない＝撃たない） |
| 無効化 | OI増加でもすぐ水準内へ。OIデータが欠ける日 |

## 既棄却との差

- L-BREAK / 案2の高値抜け: OIで分けない
- EH-01R: 入口凍結で退出だけ変えて Set C 全滅。今回は入口を「同時撃ちしない＋OI増加だけ」
- 派生botと同じOIを使うので、軸3は満点にしない

## 実装ロジック案（②・未検証）

### 実証①
- 抜け: 確定15分終値 > 直近箱高値
- OI: その15分で OI 変化率 > 0（先読みなし。確定区間のみ）
- 入口: 次の数本の1分で、箱高値±帯への押しから終値が箱の上
- 退出: 現行ブラケット
- 対照: 同じ抜けで OI 減少側（差を読む。単独EVだけ見ない）

### 実証②
- OIは「増加」ではなく「直近中央値より高い水準が持続」
- トリガーは同じ押し
