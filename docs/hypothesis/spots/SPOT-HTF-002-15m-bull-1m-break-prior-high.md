# SPOT-HTF-002: 上位足の陽線場面で、1分が直前15分高値を更新

status: testing  
created: 2026-08-25

## 仮説（一文）

15分足が確定陽線のあと、1分足が「ひとつ前の確定15分」の高値を終値で更新すると、追随の買いが続きやすい。

## 根拠

- 高値更新は15分の継続。1分は抜けた瞬間だけを取る
- 誰が損するか: 直前15分の高値で売った人、レンジ上限だと思っていた人
- 無効化: 更新がすぐ否定されて確定15分の安値を割る

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定した15分陽線 |
| 確認 | 直前の確定15分高値がレジとして残っている |
| トリガー | 1分終値がその高値を上にクロス |
| 方向 | ロング（陰線なら安値割れショート） |
| 無効化 | 上位足が陰転、抜けがだましで戻される |
