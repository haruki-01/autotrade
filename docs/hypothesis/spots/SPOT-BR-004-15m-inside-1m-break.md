# SPOT-BR-004: 確定15分インサイドの箱を、1分で片側に抜ける

status: proposed  
created: 2026-08-25  
枠: 12h / 1.00% / 1:1.5 / 上位足は確定後のみ / 1分はトリガーだけ

## 仮説（一文）

確定した15分足が、直前の確定15分の高値・安値の内側に収まった（インサイド）あと、1分足がそのインサイドの高値または安値を終値で抜けると、抜けた方向へ短期に出やすい。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定15分が、ひとつ前の確定15分のレンジに完全に収まる |
| 確認 | インサイドが確定している（今の15分の途中では判断しない） |
| トリガー | 次の15分区間の1分終値が、インサイド15分の高値または安値を更新 |
| 方向 | 抜けた側 |
| 無効化 | 抜けた直後にインサイド内へ戻り、反対側まで割る |

## なぜそうなりそうか

- 誰が払うか: インサイドの中で両方向に張り合っていた人。片側が折れる
- 場面が狭い: 毎日何本もあるわけではない。案2の「毎15分の陽線」より条件が強い
- リスク: インサイドが小さすぎると、1%損切りまで価格が動かない（E6/E8）

## 実装ロジック案（②・まだ検証しない）

### 実証①
- インサイド: 確定15分 high/low が直前15分の内側
- トリガー: 1分終値 > インサイド高値、または < インサイド安値
- 退出: 現行ブラケット
- フィルタ案: インサイドの幅が直近ATRの一定以上（小さすぎる箱は捨てる）

### 実証②
- 連続2本インサイド（より強い圧縮）のあと、同じ1分抜け
- 1本だけのインサイドは見送り

## まだやらないこと

- 未完成の15分をインサイド扱いすること
- ③は選定後
