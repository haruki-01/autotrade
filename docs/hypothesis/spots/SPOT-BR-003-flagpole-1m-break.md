# SPOT-BR-003: 15分の旗竿のあと、1分の旗面を竿方向に抜ける

status: superseded-weak-edge  
created: 2026-08-25  
枠: 12h / 1.00% / 1:1.5 / 上位足は確定後のみ / 1分はトリガーだけ

## 仮説（一文）

確定15分で実体の大きい旗竿が出たあと、1分足が小さく逆方向に畳まれ（旗面）、旗竿の始点は割らずに旗面の端を竿方向へ終値で抜けると、竿と同じ方向へ続きやすい。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定15分1本（または2本）で、はっきりした方向の実体（旗竿） |
| 確認 | そのあと1分が竿と逆に小さく往復。竿の始点（ロングなら竿の安値）は割らない |
| トリガー | 1分終値が旗面の高値（ロング）または安値（ショート）を更新 |
| 方向 | 旗竿と同じ |
| 無効化 | 旗面が竿の始点を明確に割る。畳みが長すぎて旗竿の意味が消える |

## なぜそうなりそうか

- 誰が払うか: 旗竿で遅れて追いかけた人が旗面で吐く。吐き終わりで再開する側が取る
- 案2の押し目との差: 「いつもそこにあるEMA」ではなく、**直前の急なレッグに対する畳み**だけ
- 伸び: 旗竿の高さの一部。1.5%利確と相性がよい日と、竿が小さすぎて届かない日がある

## 実装ロジック案（②・まだ検証しない）

### 実証①
- 旗竿: 確定15分の実体が、直近20本の15分実体の上位quantile
- 旗面: その後 M 本の1分が高値安値とも竿の内側
- トリガー: 1分終値が旗面高値超え（竿が陽線のとき）
- 退出: 現行ブラケット

### 実証②
- 旗竿を確定1時間の大実体にする（場面は減る）
- 旗面とトリガーは1分のまま
