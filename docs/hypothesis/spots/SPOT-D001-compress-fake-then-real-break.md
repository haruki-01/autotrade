## 仮説（一文）

長めの値幅圧縮のあと、一度上抜けして失敗（圧縮帯／ブレイク水準へ回帰）し、そのあと再び同じ方向に突破した局面では、初回ブレイク追随より上に伸びやすい。

## 構造

| 部品 | 定義 |
|------|------|
| 事前 | 実現ボラが直近平均より圧縮（ATR% が SMA(ATR%) の 0.75 倍未満が続く） |
| だまし | 日足で HH20 を終値上抜けしたあと、数日以内にそのブレイク水準を終値で割り込む |
| 確認 | だまし確定後、再び HH20 を終値上抜け（本突破） |
| トリガー | 実証①: 本突破の初日＋4H確認 / 実証②: 本突破後のブレイク水準再テスト支え |
| 方向 | ロング |
| 無効化 | 本突破後すぐ圧縮帯内へ戻る、またはだまし安値（回帰安）を更新 |

## 市場の見落とし

- 初回ブレイクに飛びつく bot／裁量が多く焼ける
- 焼けた参加者は再突破を遅れて追うか追えない
- 「圧縮→一発勝負」だけ見て、**失敗のあとの二度目**を別物として扱わない
