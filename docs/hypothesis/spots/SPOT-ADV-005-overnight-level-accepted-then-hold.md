# SPOT-ADV-005: 薄い時間に守られていた水準が、厚い時間の確定足で折れたあと、overnight在庫の損切が続く

status: proposed  
created: 2026-08-25  
評価軸: [MARKET_ADVANTAGE_AXES.md](../../master/MARKET_ADVANTAGE_AXES.md)

## 仮説（一文）

アジアなど薄い時間に、丸見えの高値/安値が何度も守られているとき、グリッド・レンジbotとovernight裁量はその水準をトレンド未発生だと思っている。ロンドン以降に **15分終値がその水準の外で確定**したあと、水準への最初の戻りが支えにならず外側で1分が続ければ、薄い時間の守り側の損切が半日続きやすい。

## 市場の3層が何をするか

| 層 | この局面での行動 |
|---|---|
| 人 | アジア中はレンジ。ロンドン初動のヒゲで飛び乗る人も多い |
| 定番bot | **ロンドン開始の1分で箱を割った瞬間に撃つ**（BR-002と同じ時刻）。ここは混雑・逆選択 |
| 派生bot | セッションvolでゲートする個体はいるが、overnight在庫の「確定折れ」待ちは少ない |

## 優位の本体

BR-002 は「厚い時間に箱を1分で割る」＝定番ORBと同時。速さでも早期でもない。  
こちらは市場が認知できるセッション解消のうち、**初tickを譲る**。認知の確定（15分終値）のあと、overnightが「まだレンジ」と誤認し続けているあいだの継続が本体。  
早期性は「日足トレンドの前」ではなく、「overnightがトレンドを認めない」こと。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | UTC 0〜8 の確定15分で、高値または安値が複数回守られた箱。幅は狭い日だけ |
| 確認 | UTC 7 以降、確定15分終値が箱の外。同じ15分の中の最初の1分抜けでは入らない |
| トリガー | 確定後、1分が箱縁まで戻して終値が箱の外を維持（ロールリバーサルの初回ではなく、確定折れ後の維持） |
| 方向 | 折れた側 |
| 無効化 | 15分は外で確定したが、すぐ次の15分が箱内。またはアジア箱が広い |

## 既棄却との差

- BR-002 / 案2の高値更新: 割れの1分に入る
- D-007: ロンドン解消後のNY前再テスト、に近い。こちらはovernight守り＋15分確定を必須にする

## 実装ロジック案（②・未検証）

### 実証①
- 箱: アジア確定15分の high/low、接触2回以上、幅フィルタあり
- 受け入れ: ロンドン以降の確定15分 close が箱の外
- 入口: その後 H 時間以内の1分が、箱縁タッチかつ close が箱の外
- 退出: 現行ブラケット
- 対照: 受け入れを待たず、最初の1分抜けで入る版（BR-002相当）。差が無ければ優位なし

### 実証②
- 受け入れを1時間終値にする（より遅い、混雑耐性↑、回数↓）
