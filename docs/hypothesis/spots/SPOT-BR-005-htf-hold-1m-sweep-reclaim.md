# SPOT-BR-005: 上位の押し安値は守り、下位だけ狩って取り戻してから入る

status: proposed  
created: 2026-08-25  
枠: 12h / 1.00% / 1:1.5 / 上位足は確定後のみ / 1分はトリガーだけ

## 仮説（一文）

1時間足の押し安値は割れていないのに、15分または1分が直近安を少し割ってすぐその安を終値で取り戻したあと、1分が狩りの起点になった小高値を更新すると、上へ巻き戻りやすい（ショートは逆）。

## 案2との違い

案2は「押しが来たらEMAで買う」。ここでは **一度わざと安を割らせて、失敗した売りを確認してから** 入る。最初の押しでは入らない。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定1時間で HL が残っている（上昇構造）。ショートなら LH が残っている |
| 確認 | 下位が直近安をわずかに更新したあと、その安を終値で回復（失敗した下抜け） |
| トリガー | 回復後、1分終値が「狩りが始まる直前の小高値」を更新 |
| 方向 | 上位構造と同じ（ロングなら上） |
| 無効化 | 1時間の押し安値を終値で割る。取り戻しが弱く、割った安の下で定着 |

## なぜそうなりそうか

- 誰が払うか: 下位の安値割れで売った人、ストップを狩られた人。戻しで買い戻す
- 見落とし: 下位だけ見ている売り。1時間の構造を見ていない
- 深い① D-004 の、ブラケット用（1時間×1分）版

## 実装ロジック案（②・まだ検証しない）

### 実証①
- 1時間 HL 維持
- 1分安値が、直近 N 本1分安を下抜け → その後数本以内に終値がその安を上回る
- トリガー: 1分終値 > スイープ開始前の直近1分高値
- 退出: 現行ブラケット

### 実証②
- スイープを確定15分の安値割れ→次の確定15分で取り戻し、とする
- 入る瞬間だけ1分（取り戻し後の15分高値を1分が更新）

## まだやらないこと

- 下位の安値割れそのもので逆張りすること（狩りの最中に買う）
- ③は選定後
