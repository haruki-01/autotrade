# SPOT-BR-008: 15分の急なレッグの半値まで戻し、1分で再開する

status: superseded-weak-edge  
created: 2026-08-25  
枠: 12h / 1.00% / 1:1.5 / 上位足は確定後のみ / 1分はトリガーだけ

## 仮説（一文）

確定15分で実体の大きいレッグが出たあと、1分足がそのレッグの概ね半値まで戻してレッグ始点は割らず、半値付近からレッグ方向へ1分高値を更新すると、再加速しやすい。半値を大きく割る押しは失敗しやすい。

## 案2との違い

案2は「15分EMAまで戻したら買う」。EMAはいつもそこにあるので、弱い押しも強い押しも同じ扱いになった。ここでは **直前レッグの半値** という測れる場所だけを押しの質にする。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 確定15分（または連続2本）の大きなレッグ。方向がはっきりした実体 |
| 確認 | 1分がレッグ高値から概ね38〜50%戻す。レッグ始点は割らない |
| トリガー | 半値帯で下げが止まり、1分終値が直近の1分戻り高値を更新（ロング） |
| 方向 | レッグと同じ |
| 無効化 | レッグ始点割れ。半値を大きく超えて61%超まで沈み続ける |

## なぜそうなりそうか

- 誰が払うか: レッグ高値で追いかけた人が半値まで吐く。深押しを「転換」と見た売りが、半値支えで巻き込まれる
- 深い① D-006 の15分×1分版
- 伸び: レッグ高値の再更新。利確1.5%に届くかはレッグの大きさ次第

## 実装ロジック案（②・まだ検証しない）

### 実証①
- レッグ: 確定15分の（高値−安値）または実体が、直近20本より大きい
- 半値: レッグ高値と始点の中点±小さい帯
- トリガー: 1分が帯に触れたあと、1分終値 > 直近数本の1分高値
- 退出: 現行ブラケット

### 実証②
- レッグを確定1時間の急騰/急落にする
- 押しとトリガーは1分のまま（半値帯も1時間レッグで測る）
