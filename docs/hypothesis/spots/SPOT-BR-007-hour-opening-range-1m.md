# SPOT-BR-007: その時間の最初の15分箱を、後半の1分で割る

status: superseded-weak-edge  
created: 2026-08-25  
枠: 12h / 1.00% / 1:1.5 / 上位足は確定後のみ / 1分はトリガーだけ

## 仮説（一文）

各時間の最初の確定15分が「その時間の始値レンジ」になったあと、同じ時間の後半に1分足がその15分の高値または安値だけを終値で割ると、その時間〜数時間はその方向に偏りやすい。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | 毎時 00〜15 の確定15分1本（始値レンジ）。値幅が直近より狭い日だけ採用 |
| 確認 | 同じ時間の 16〜59 分。まだ始値レンジの片側しか割っていない |
| トリガー | 1分終値が始値レンジの高値または安値を更新 |
| 方向 | 割れた側 |
| 無効化 | 同じ時間内に反対側も更新する（中身が両方割れる＝方向がない） |

## なぜそうなりそうか

- 誰が払うか: 時間の前半でレンジだと思って逆に張った人
- BR-002（アジア箱）との差: 毎日の「時間の箱」。アジアに限らない。その代わり質は落ちやすい
- リスク: 毎時撃てると月50回は余裕だが、情報がない時間も混ざる（E8）。**狭い始値レンジの時間だけ**が本体

## 実装ロジック案（②・まだ検証しない）

### 実証①
- 始値レンジ: 各時00分起点の確定15分 high/low
- 幅フィルタ: その15分ATR（または高値−安値）が直近24本の中央値未満
- トリガー: 16分以降の1分終値抜け。反対側はまだ未更新
- 退出: 現行ブラケット

### 実証②
- 箱を4時間の最初の15分（または最初の1時間）にする。回数は減る
- トリガーは1分抜けのまま

## まだやらないこと

- 幅フィルタなしで毎時撃つこと
- 未完成の「今の15分」を始値レンジにすること
- ③は選定後
