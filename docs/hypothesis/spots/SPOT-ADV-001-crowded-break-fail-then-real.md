# SPOT-ADV-001: 定番ブレイクbotの初回を餌にし、失敗したあとだけ本方向に乗る

status: proposed  
created: 2026-08-25  
評価軸: [MARKET_ADVANTAGE_AXES.md](../../master/MARKET_ADVANTAGE_AXES.md)

## 仮説（一文）

公開OHLCVの定番（15分高値抜け・ORB・Donchian）が初回に一斉に撃ったあと、その抜けが箱の中へ戻って失敗が確定し、そのあと再び同じ方向へ箱の外で15分が確定した局面では、初回より続きやすい。1分は「本突破の確定15分のあと、箱が支えになった最初の触れ」だけに使う。

## 市場の3層が何をするか

| 層 | この局面での行動 |
|---|---|
| 人 | 初回抜けを「トレンド開始」と見て追う。失敗で火傷し、二度目を遅れる |
| 定番bot | **初回の足確定と同時に撃つ。** ここが混雑。失敗で損切が箱の中へ戻る燃料になる |
| 派生bot | 初回でもOI条件を足す個体はいる。失敗確定まで待つ個体は少ない（遅くなるため） |

## 優位の本体（速さではない）

市場は初回抜けを**認知できる**。こちらはそれを早く取らない。  
優位は「認知された偽トレンドが壊れたあと、焼けた定番の損切が終わってから来る本方向」＝**二階**。

## 構造

| 部品 | 内容 |
|------|------|
| 事前 | はっきりした箱（アジアまたは直近の圧縮）。定番が撃ちたくなる丸見え高値/安値 |
| 確認 | 1分または15分が箱を超えたあと、箱の内側へ戻り、超えた側の足が否定される（初回失敗） |
| トリガー | 失敗後、同じ方向へ15分終値が箱の外で確定。そのあと1分が、壊れた箱の縁を支え/抑えとして触れて反発 |
| 方向 | 二度目に受け入れられた側 |
| 無効化 | 二度目もすぐ箱の中へ。三度目まで待つ信仰 |

## 既棄却との差

- HTF-002 / BR-006: 初回や「同じ高値の二度目抜け」を1分で同時に取る → 定番と同じ時刻
- D-001 日足HH20: 時間尺度が枠（12h）と違う。ここでは箱と定番ブレイクの時間尺度に合わせる
- 案2: 陽線フィルタ。定番の失敗を見ていない

## 実装ロジック案（②・未検証）

### 実証①
- 箱: 確定15分 N 本の高値/安値
- 初回失敗: 1分終値が箱を超えたあと K 本以内に箱内へ戻る
- 本突破: その後の確定15分終値が箱の外
- 入口: 本突破後、1分が箱縁で反発（クロス）
- 退出: 現行ブラケット

### 実証②
- 初回失敗を「15分が箱外で確定した翌15分が箱内で確定」だけにする（1分の先走りを捨てる）
- 入口は本突破の15分確定の最終1分（遅くなるが混雑初動を避ける）
