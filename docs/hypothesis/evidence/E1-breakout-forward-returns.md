# E1 Evidence — Donchian ブレイク後の前方リターン

作成: 2026-08-22  
目的: ロジック実装の前に、「日足20日高値/安値ブレイク後に、レバなしで正の裾があるか」を見る。  
これは formal eval の代替ではない。スクリーニング。

## データ

| 項目 | 値 |
|------|-----|
| ソース | Binance Vision BTCUSDT spot（formal lock と同系統の実足） |
| ファイル | `data/cache/BTCUSDT_binance_spot_1d_2023-05-26_2024-12-31.csv` |
| 主評価窓 | 2024-01-01 → 2024-12-31（Set B） |
| 補助 | ファイル全体（2023-05〜2024） |
| 定義 | 前日までの20日 Donchian 高値/安値を超え/下回った日を「新規シグナル」（連続日の初日） |
| リターン | シグナル日終値 → N日後終値。ショートは符号反転 |
| コスト目安 | 往復 0.15%（0.0015）を「費用クリア」の粗い線 |

制約: 2024は強い上昇年（Buy&Hold 約 **+112%**）。ショート不利・ロング有利のレジームバイアスあり。

| 3d | 38 | +0.94% | +0.35% | 53% | 53% |

→ **上抜け後は平均・中央値ともプラス。10〜20日で費用線を明確に超えやすい。**  
E1（ロング追随）を棄却する根拠は、この窓では出なかった。

### ショート（下抜け）— Set B

| 前方 | n | 平均 | 中央値 | >0 比率 |
|------|---|------|--------|---------|
| 1d | 10 | +0.08% | -0.60% | 30% |

→ **ショートは平均マイナス（＝下抜け後も上がりやすい／ショートが負けやすい）。**  
両建て Donchian のショート脚は、少なくとも2024ではエッジ候補から外す。

### 構造退出（10日安値割れまで保有）— 上抜けのみ Set B

| n | 平均 | 中央値 | 勝率 |

| 25 | +3.33% | **-3.40%** | 32% |

→ 平均プラス・中央値マイナス＝**少数の大勝ちに依存する歪度**。  
「勝率を上げる」最適化は誤り。大勝ちを切らない退出が本体、という E1 の物語と整合。
