# 固定ブラケット枠（1:2・保有上限6時間）

status: **枠は確定。15分足の価格・出来高・時間帯からは情報が出ない（25条件×3期間で全滅）**
指示: リスクリワード1:2固定、保有時間上限6時間、レバ3倍で6時間以内決済率90%程度
関連: [目標の逆算](../master/TARGET_MODEL.md) ·
[月50エントリー要件](./postmortems/2026-08-24-trade-rate-requirement.md)

## なぜこの枠が良いか

**判定基準が理論から出ます。** ドリフトのない価格に対する 1:2 ブラケットの
当たり率は、幅の比だけで決まります。

```
P(利確が先) = 損切り幅 / (損切り幅 + 利確幅) = 1/3 = 33.3%
```

つまり**勝率が33%台なら、そのシグナルには情報が無い**と即断できます。
値幅・RR・保有上限が全条件で共通なので、条件ごとに変わるのは「いつ入るか」
「どちら向きか」だけ。one-point change が構造的に守られます。

さらに、この枠は**頻度の問題を解消します**。保有上限6時間・中央保有1時間なので、
1枠しか持てない現行エンジンでも月260回以上撃てます。
月50エントリーの要件はもう制約ではありません。

## 値幅の決定（実測）

BTCUSDT 15分足に対し、各期間4,000点のエントリーを無作為に打って前進走査。
同じ足で損切りと利確の両方に触った場合は**損切り優先**（足の中の順序は
15分足からは分からないので悲観側）。

| 損切り幅 | 利確幅 | 6時間以内決済率 | タイムアウト | 中央保有 |
|---|---|---|---|---|
| 0.25% | 0.50% | 95.7% | 4.3% | 3本 |
| 0.30% | 0.60% | 93.0% | 7.0% | 3本 |
| **0.35%** | **0.70%** | **89.9%** | **10.1%** | **4本** |
| 0.40% | 0.80% | 86.5% | 13.5% | 5本 |
| 0.50% | 1.00% | 79.2% | 20.8% | 8本 |

**採用: 損切り 0.35% ／ 利確 0.70%**（決済率 89.9%、目標90%に最も近い）

レバ3倍・証拠金30 USDT（想定元本90 USDT）なら、損切り時 −0.32 USDT、
利確時 +0.63 USDT。中央保有は4本＝1時間。

## 損益分岐勝率 — ここが構造的な壁

コストの比率は損切り幅だけで決まり、**サイジングでは動きません**。

```
往復コスト / 許容損失 = コスト率 / 損切り幅 = 0.150% / 0.35% = 42.9%
損益分岐勝率 = (1 + 0.429) / (1 + 2) = 47.6%
```

| 手数料の前提 | 往復コスト率 | コスト/許容損失 | 損益分岐勝率 | 対照からの必要上振れ |
|---|---|---|---|---|
| 現行（両側テイカー） | 0.150% | 42.9% | **47.6%** | **+16.9pt** |
| 入口メイカー / 出口テイカー | 0.095% | 27.1% | 42.4% | +11.7pt |
| 両側メイカー | 0.060% | 17.1% | 39.0% | +8.3pt |
| 両側メイカー・スリッページ無し | 0.040% | 11.4% | 37.1% | +6.4pt |

**「6時間以内に90%決済」と「テイカー手数料」は直接ぶつかります。**
6時間で決済率90%を出すには損切りを0.35%まで狭めるしかなく、そこまで狭いと
コスト率0.150%が許容損失の43%を食います。

## 検証結果 — 25条件 × 3期間 = 75通り

15分足で入口条件を25本用意しました（トレンド継続・逆張り・ブレイク・
ブレイクの逆張り・ボラ収縮・出来高急増とその逆・連続足とその逆・
上位足フィルタ付き押し目・時間帯・急変の順張りと逆張り）。
無作為エントリーの対照2本を同じ計測系で並走させています。

合計 **254,809 トレード**。

|---|---|---|---|---|---|---|
| `br_runs_fade_3` | 3連続後の反転 | 24,584 | 259.6 | 32.2% | +1.5pt | +2.52 |

判定は理論値33.3%ではなく**実測の対照30.7%**に対して行いました。
同足の損切り優先ルールで計測系が理論より2.6pt低く出るので、対照を基準に
すればそのバイアスが両側で打ち消えます。

| | 結果 |
|---|---|
| 損益分岐（47.6%）を超えた | **0** |
| 費用後に黒字 | **0** |
| 対照比 z ≥ 2 | 2（25本試して2本なので偶然の範囲。多重検定なら z≥2.9 が必要） |
| 月50回以上撃てた | **18** |

**25条件すべてで EV ≈ −コスト**（EVの範囲 −0.200〜−0.127 に対し往復コスト
−0.135）。どのシグナルも当たり外れに情報を足していません。

## この結論の確かさ

検出力は十分です。最大の条件（n=24,584）で勝率の標準誤差は0.30ptなので、
**1pt程度の差でも検出できます**。実際に +1.5pt を捉えています。
必要な +16.9pt が見えていないのは検出力不足ではなく、
**その大きさの歪みが無い**ということです。

これは「まだ見つかっていない」ではなく「**15分足のOHLCVには無い**」という
強い否定的結果です。

## 次にやるべきこと

必要上振れが +16.9pt から動かないと、勝率側の探索は無意味です。
順序としてはコストを先に下げます。

**A. 約定モデル（最優先）**
入口を指値にすると必要上振れが +16.9pt → +11.7pt、両側メイカーなら +8.3pt。
これは勝率探索で埋まる可能性が出てくる水準です。ただし指値は約定しないので、
**未約定を数える約定モデル**が必要（現行エンジンは成行のみ）。

**B. 15分足OHLCV以外の情報を入口に使う**
価格・出来高・時間帯からは出ませんでした。残っているのは
OI・funding・basis・taker flow（`binance_derivatives.py` で取得済み）。
EH系で15分足では効かなかったものですが、**ブラケットを固定した枠での再試験は
まだしていません**。EH系は損切りをATRで動かしていたので、条件が違います。

**C. 枠の再交渉**
決済率90%を70%まで落とせば損切りは0.60%まで広げられ、コスト/許容損失は
43% → 25%、必要上振れは +16.9pt → +9.6pt になります。
保有上限6時間は維持したまま、タイムアウト率を上げる方向です。

推奨は **A → C → B**。A と C はどちらも必要上振れを半分にする効果があり、
どちらも勝率探索の前にやるべきことです。
