## なぜこの枠が良いか

**判定基準が理論から出ます。** ドリフトのない価格に対する 1:RR ブラケットの
当たり率は、幅の比だけで決まります。

```
P(利確が先) = 1 / (1 + RR)
```

1:1.5 なら 40%。勝率がそこなら情報ゼロと即断できます。
値幅・RR・保有上限が全条件で共通なので、条件ごとに変わるのは「いつ入るか」
「どちら向きか」だけ。one-point change が構造的に守られます。

頻度も制約ではありません。保有上限6時間・平均保有3.3時間なので、
1枠でも月200回以上撃てます。

## 変数は3つ、順番に決まる

```
帰無     w0 = 1 / (1 + RR)
損益分岐 w* = (1 + c/s) / (1 + RR)     c = 往復コスト率, s = 損切り幅
必要上振れ(pt)  = (c/s) / (1 + RR)
必要上振れ(倍率) = 1 + c/s               ← RR に依存しない。幅だけで決まる
```

シグナルが確率をどれだけ動かせるかは、小さいドリフト μ で展開すると

```
θ ≥ 2c / (s² · RR)                     θ = 2μ/σ²
```

**必要なシグナル強度は幅の2乗と RR に反比例します。** 幅を広げるほうが効く。
ただし6時間の値動きの標準偏差（15分足ATR × √24 ≈ 1.35%）を損切り+利確の
合計が超えると、ブラケットは届かず「6時間で成行決済」になります。

```
損切り × (1 + RR) ≲ 1.35%              ブラケットが機能する条件
```

RR を上げると幅を狭めねばならず、コスト比が悪化します。
これが RR を無限に上げられない理由です。

## 指値にしたときのコスト

入口は指値（メイカー）、利確も指値で置ける（メイカー）、
**損切りだけは成行にせざるを得ません**（指値だと急落で約定しない）。
スリッページもテイカー側の脚にだけ乗せます。

メイカー 0.020% / テイカー 0.055% / スリッページ 0.020%。
1:1.5 なら出口の約60%が損切り側なので、往復 **0.0730%**
（両側テイカーなら 0.150%。約半減）。

### 指値で増えるリスク（実測）

| リスク | 実測 | 損か |
|---|---|---|
| 未約定 | 現値・1本待ちで **1%** | 機会損失のみ |
| 逆選択 | 有利側に置いて約定率77%まで落としても勝率は下がらない（平均 **+0.7pt**） | **観測されず** |
| 遅延 | 平均1本（15分） | 決済率がわずかに落ちる |

手数料の節約は勝率 4.4pt 分の価値。実測の劣化はゼロなので、
**指値にして損はありません。** ただしこの計測は「足の中で触れたら約定」
という仮定。実運用ではキュー位置で約定率は悪化する方向です。

funding は平均保有3.3時間で 1トレードあたり約0.004%。往復コストの6%で、
判断を変える大きさではありません。

## 比と幅の総当たり（決済率の下限ごと）

月50回以上を満たす範囲で、θ が最小の形。

| 決済率の下限 | 最良の RR | 損切り | 利確 | 実際の決済率 | 月上限 | 必要上振れ |
|---|---|---|---|---|---|---|
| 90% | 1:2.0 | 0.35% | 0.70% | 90% | 378 | +7.3pt |
| 85% | 1:2.5 | 0.35% | 0.88% | 87% | 344 | +6.5pt |
| 80% | 1:4.0 | 0.35% | 1.40% | 81% | 296 | +4.8pt |
| 75% | 1:2.5 | 0.50% | 1.25% | 75% | 245 | +4.5pt |
| **70%** | **1:1.5** | **0.70%** | **1.05%** | **70%** | **218** | **+4.2pt** |

| 50% | 1:5.0 | 0.70% | 3.50% | 52% | 177 | +2.0pt |

**採用: RR 1:1.5 / 損切り 0.70% / 利確 1.05%**（決済率70%の下限での最良）。
決済率90%は仮置きだったので、70%まで譲って幅を広げた。
下限を外すと最良は 1:5 / 2.00% になるが、これは決済率15%で
**もはやブラケットではない**（θ の導出が成り立たない）。

## 検証結果 — 現行枠、25条件 × 3期間

合計 **197,301 トレード**。判定は理論値40.0%ではなく実測の対照36.8%に対して行う
（同足の損切り優先で計測系が 3.2pt 低く出るため）。

対照から損益分岐までの距離は **+7.4pt**（理論上の +4.2pt より広い。
悲観ルールのぶん）。

旧枠では最大の上振れが +1.5pt で必要 +16.9pt の1割にも届きませんでした。
**現行枠では +3.9pt / 必要 +7.4pt = 53%。** 黒字には届かないが、
「情報が無い」ではなく「足りない」に変わりました。

多重検定を通った3本はすべて**順張り（継続）**です。逆張りは対照を下回るものが多く、
15分足の歪みは（あるとすれば）継続側にあります。

## 次に試したこと — OHLCV 以外の入口（3期間）

同じブラケットで OI / funding / basis / taker の7条件を回した。
Set A は先物開始前（〜2019-09）が欠損、Set B も metrics に穴がある。
ある期間だけで測ると誤るので、3期間プールで読む。

| logic | 狙い | 合計n | 回/月 | 勝率 | vs 40% | z |
|---|---|---|---|---|---|---|
| `br_fund_cheap` | funding が安い方向に乗る | 5,438 | 57.8 | 40.9% | **+0.9pt** | +1.32 |
| `br_basis_fade` | プレミアム極端の逆張り | 9,220 | 97.1 | 39.4% | −0.6pt | −1.04 |
| `br_oi_follow` | OI増加の方向に乗る | 10,229 | 107.5 | 39.0% | −1.0pt | −1.82 |
| `br_taker_fade` | taker 優勢の逆張り | 14,123 | 148.4 | 38.5% | −1.5pt | −3.32 |
| `br_taker_follow` | taker 優勢の方向に乗る | 14,227 | 149.5 | 38.1% | −1.9pt | −4.14 |
| `br_oi_fade` | OI急増の逆張り | 7,749 | 81.4 | 36.3% | −3.7pt | −6.11 |
| `br_fund_fade` | funding 混み合い方向に乗る | 5,485 | 58.3 | 35.7% | **−4.3pt** | −6.35 |

**黒字 0、z ≥ 2 は 0。** 最良の `br_fund_cheap` でも +0.9pt（必要 +4.2pt の2割）。
OHLCV の最良（+3.9pt）にも届かない。

読み取れること:
- **混み合いに乗るのは明確に負け**（funding crowded z=−6.35、OI fade z=−6.11）。
  これは「情報が無い」ではなく「逆方向の情報がある」
- 安い側に乗るのはわずかにプラスだが、損益分岐には全く足りない
- 15分足の派生データも、このブラケットの必要上振れは埋められない

残る候補は「OHLCV順張り3本に、混み合いを**避ける**フィルタを足す」こと。
ただし one-point change を守るなら、フィルタは1つだけ。
`br_runs_5`（+3.9pt）に funding 安い側だけを残す、が最初の一手。

→ **実施済み。勝率はほぼ動かず（41.4% → 41.7%）、頻度が月56回 → 7回に落ちて
月50回要件を割る。** フィルタは勝率を足さず、回数だけ削る。この方向は打ち止め。
